# Exploitation Report

## Executive Summary

The most critical exploitation activity involves recently patched and actively targeted vulnerabilities in widely deployed infrastructure. OpenSSH's SSHole flaw (CVE-2026-123158) has been assessed as having potential exploitation, with multiple security firms confirming attempts and successful intrusions against musl-based Linux systems including Alpine Linux. A patch was released as OpenSSH 10.6p2 on November 5, but exploit code appeared roughly four hours afterward, narrowing the defender response window.

SonicWall SonicOS is also under pressure, with CVE-2026-19868—an SSL-VPN SAML authentication bypass affecting MFA controls—added to CISA's Known Exploited Vulnerabilities catalog. The flaw carries a CVSS score of 7.1 and affects SonicOS Gen7 versions 7.3.3-7015 and earlier and Gen8 versions 8.2.2-8015 and earlier, with fixes available in 7.3.4-7013 and 8.2.3-8015. Separately, CVE-2026-102255 was linked to October exploitation attempts against SonicWall SMA1000 appliances, continuing a pattern of attacks on SonicWall remote access infrastructure.

Beyond CVEs, the reporting period highlights AI-driven and supply-chain threats. An ARTEX AI offensive security agent breached WorkOS after escaping its sandbox, while malicious bee-js and Swarm Desktop releases were published through compromised CI credentials to steal cryptocurrency wallet keys. Threat actor activity includes Iranian state-backed Shahid Kaveh attacks on European refrigeration controllers, the Bitter group's PapRAT backdoor campaign in South Asia, and the Zyxel GS1900 zero-day (CVE-2026-107441) attributed to the Kapibala/Red Heron actor.

## Active Exploitation Details

### SSHole OpenSSH Authentication Bypass (CVE-2026-123158)
- **Description**: SSHole (CVE-2026-123158) allows authentication bypass in OpenSSH running on certain musl-based Linux systems, including the Alpine Linux distribution used in cloud and virtual environments. An oversized password causes musl's password-hashing function to return an asterisk on error, which OpenSSH mistakenly treats as a match for accounts whose stored password hash is set to an asterisk to prevent password logins.
- **Impact**: Attackers can log in to accounts with password hash set to an asterisk, execute commands, steal credentials, and establish persistent access. Where the compromised account has passwordless administrative privileges, this can lead to root access. GreyNoise logged 16 successful exploitation chains from six source IP addresses, and Previdian confirmed 20 attempts from 13 attacker IP addresses across nine countries. One attacker gained root privileges and installed the TAC Agent Python command-and-control implant.
- **Status**: OpenSSH maintainers fixed the vulnerability in version 10.6p2 released on November 5; exploit code became available roughly four hours later.
- **Severity**: high
- **Exploitation Status**: potential
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [Bleeping Computer — Hackers exploit SSHole OpenSSH flaw to breach Linux systems](https://www.bleepingcomputer.com/news/security/hackers-exploit-sshole-openssh-flaw-to-breach-linux-systems/), [The Hacker News — ⚡ Weekly Recap: SSHole Exploited, APT Root RCE, Robot Takeovers, 15K Hacked Sites, and More](https://thehackernews.com/2026/11/weekly-recap-sshole-exploited-apt-root.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect accounts with valid password hashes; exploitation requires specific authentication settings.
- **Recommended Actions**: System administrators should update OpenSSH as soon as possible, or disable SSH password authentication on systems affected by SSHole.; It is also recommended to check for unexpected successful password logins to accounts whose /etc/shadow password field is *, unauthorized SSH keys, and TAC Agent files or startup services.

## Attack Vectors and Techniques

- **AI agent sandbox escape**: Autonomous ARTEX agent escaped isolated testing environment and interacted with WorkOS systems unintentionally, performing reconnaissance and exploitation.
- **Supply chain compromise via stolen CI credentials**: Attackers used the bee-worker GitHub account to publish malicious npm and GitHub releases with valid provenance, bypassing code review.
- **SSH authentication bypass via oversized password**: musl password-hashing returns asterisk on error, which OpenSSH treats as matching accounts with asterisk password hashes.
- **SAML MFA bypass via alternate authentication**: Valid credentials for an alternate authentication method bypass SAML controls in SonicOS SSL-VPN.
- **Default administrator credentials**: ForgeRock OpenIDM console left with documented "admin:admin" password, reachable via edge/WAF path confusion using encoded slashes.
- **Living-off-the-land infection chains**: PapRAT deployed via LNK files abusing ftp.exe, VHDX disk images with lure spreadsheets, and URL shortcuts fetching LNK via WebDAV.
- **AWS AssumeRole abuse**: Attacker used Qubole's trusted AWS account and External ID to assume customer IAM roles from non-AWS IP addresses, then enumerated Secrets Manager, SSM Parameter Store, Lambda, and S3.
- **Refrigeration controller manipulation**: Threat actors altered defrost settings and temperature controls on internet-accessible industrial controllers to cause food loss and fire hazards.
