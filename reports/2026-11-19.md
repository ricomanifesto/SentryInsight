# Exploitation Report

## Executive Summary

CISA added four vulnerabilities to its Known Exploited Vulnerabilities catalog, including CVE-2026-90436 in Apache Axis, which is actively exploited in the wild alongside 4EverAble2Shell flaws affecting N-able N-central to deploy cryptocurrency miners. Rapid7 detected exploitation of CVE-2026-90436 against Atlassian Confluence Data Center in a customer environment, with attackers running shell commands and enumerating compromised environments.

Two critical NGINX vulnerabilities dubbed "nginx2root"—CVE-2026-123007 and CVE-2026-123633—allow unauthenticated remote code execution and can be chained with a separate Linux kernel SCTP flaw to gain root access and escape Docker containers. Patches are available in NGINX Open Source 1.30.7 and 1.31.9, but the exploitation status for these flaws remains unknown based on the supplied evidence. Additional critical flaws affect F5 BIG-IP, VMware vCenter, Apache Roller, PostgreSQL, MySQL, Oracle Database, and several CISA KEV-listed products.

Apache Roller CVE-2026-129448 is reported by the Apache Software Foundation as under active exploitation, though the supplied evidence contract assesses its exploitation status as unknown. Defenders should prioritize patching NGINX, BIG-IP, vCenter, and Axis deployments, and review CISA KEV additions for mandatory remediation timelines.

## Active Exploitation Details

### NGINX HTTP/2 Remote Code Execution (nginx2root)
- **Description**: CVE-2026-123007 is a flow-control bug that can corrupt memory in an NGINX worker; CVE-2026-123633 is a use-after-free problem affecting NGINX when it accepts HTTP/2 connections and proxies requests to a backend.
- **Impact**: Attackers can achieve unauthenticated remote code execution as the NGINX worker process; chaining with a separate Linux kernel SCTP flaw can lead to root access and Docker container escape.
- **Status**: Patches are available in NGINX Open Source 1.30.7 and 1.31.9, and NGINX Plus 37.0.8.1 or 37.3.0.1; NGINX Plus R34 to R36 has no fix listed for CVE-2026-123007. Exploitation status is unknown.
- **Severity**: critical
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123007, CVE-2026-123633
- **Reporting**: [Bleeping Computer — Critical NGINX ‘NGINX2Root’ bugs let attackers hijack servers](https://www.bleepingcomputer.com/news/security/critical-nginx-nginx2root-bugs-let-attackers-hijack-servers/), [The Hacker News — 10-Year-Old NGINX HTTP/2 Flaw Lets Unauthenticated Attackers Execute Code on Servers](https://thehackernews.com/2026/11/10-year-old-nginx-http2-flaw-lets.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: NGINX Plus R34 to R36: no fix listed for CVE-2026-123007
- **Recommended Actions**: Upgrade immediately to the latest NGINX release, or temporarily disable HTTP/2 until an upgrade is possible. However, this mitigation only covers the two "nginx2root" flaws.
- **Vendor Links**: https://nginx.org/en/security_advisories.html; https://my.f5.com/manage/s/article/K000163926

## Attack Vectors and Techniques
- **HTTP/2 memory corruption**: Crafted HTTP/2 connections trigger flow-control bugs or use-after-free conditions in NGINX worker processes
- **DNS resolution with subrequests**: Proxied server names built from variables combined with SSI or mirror subrequests trigger use-after-free in NGINX
- **Mail proxy authentication**: NGINX mail proxy authentication paths contain use-after-free conditions reachable by attackers
- **TLS 1.3 request body processing**: Reading request bodies over TLS 1.3 can trigger infinite loops in NGINX workers
- **Database memory corruption via SQL**: Low-privilege database accounts trigger memory-unsafe C and C++ code in database engines through temporary tables, object creation, or crafted queries
- **iRule and APM policy abuse**: Specific iRule commands (PEM::subscriber, MR::message route, PSC::ip_address, GENERICMESSAGE::route, DNS::scrape) or APM policy agents trigger stack-based buffer overflows in BIG-IP TMM
- **VMware Directory Service authentication bypass**: Network access to vCenter allows bypassing authentication via the Directory Service component
- **XML-RPC deserialization**: Unauthenticated deserialization of vendor extension types in the Apache Roller XML-RPC endpoint before authentication
- **Unsafe reflection**: Crafted HTTP requests access unintended controller routes in Apache Axis XML-RPC and SOAP APIs
- **Code injection via public survey context**: Crafted file-path or stream parameters during data import processing exploit REDCap code injection
- **Bytecode rewriting**: The /guardrails/test_custom_code URI in LiteLLM enables bytecode rewriting to elevate inference keys to administrative credentials
- **Improper encoding or escaping**: Unspecified vectors in Synology DSM allow remote code execution
