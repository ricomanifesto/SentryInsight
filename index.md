# Exploitation Report

## Executive Summary

Critical infrastructure and virtualization platforms face active and recently patched exploitation risks. Two NGINX HTTP/2 vulnerabilities tracked as CVE-2026-123007 and CVE-2026-123633, collectively known as "nginx2root," allow unauthenticated remote code execution on vulnerable web servers and can be chained with a Linux kernel flaw for root access. Patches are available in NGINX Open Source 1.30.7 and 1.31.9, but exploitation status remains unknown for these flaws.

A VMware vCenter Server authentication bypass, CVE-2026-123890, was exploited as a zero-day by the suspected China-nexus espionage group Armory Castle beginning in early September 2026, with patches released on November 19, 2026. Separately, CVE-2026-90436 in Apache Axis is assessed as actively exploited, with Rapid7 detecting exploitation against Atlassian Confluence Data Center; Axis 1.x has reached end-of-life and remains unpatched, requiring migration or a patched build. Additional database and management console flaws, including PostgreSQL CVE-2026-116331, MySQL CVE-2026-101786, Oracle CVE-2026-114819 and CVE-2026-91609, and ASUS Control Center Express CVE-2026-114202, have available patches but unknown exploitation status.

## Active Exploitation Details

### VMware vCenter Server Authentication Bypass
- **Description**: A critical authentication bypass vulnerability in the VMware Directory Service allows an unauthenticated attacker with network access to bypass authentication and gain unauthorized administrative access to vCenter Server.
- **Impact**: Attackers can obtain administrative access to vCenter, execute arbitrary commands, acquire files including the data.mdb database, steal SAML signing keys, forge authentication tokens, and gain control over managed virtual machines and ESXi hosts.
- **Status**: Patch available via VMSA-2026-0009 released November 19, 2026. Broadcom states no official workarounds exist, though network restrictions and firewall controls can reduce exposure. Exploitation status is unknown per the supplied evidence contract; conflicting or negative evidence is preserved.
- **Severity**: critical
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123890
- **Reporting**: [Bleeping Computer — VMware patches vCenter zero-day exploited in attacks since September](https://www.bleepingcomputer.com/news/security/vmware-patches-vcenter-zero-day-exploited-in-attacks-since-september/), [The Hacker News — Critical VMware vCenter Zero-Day Flaw Lets Network Attackers Bypass Authentication](https://thehackernews.com/2026/11/critical-vmware-vcenter-flaw-cvss-98.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: ESX itself is not affected; none of the flaws in the advisory allow code execution on an ESX host from inside a virtual machine.

## Attack Vectors and Techniques

- **HTTP/2 Flow-Control Memory Corruption**: Unauthenticated attackers send crafted HTTP/2 requests over TLS to corrupt memory in an NGINX worker, achieving remote code execution; chaining with a Linux kernel SCTP flaw enables Docker container escape and root host access.
- **HTTP/2 Use-After-Free**: When an NGINX worker runs low on connection slots while proxying HTTP/2 requests to a backend, active connections are closed and freed memory still in use by a request is accessed, enabling remote code execution.
- **VMware Directory Service Authentication Bypass**: Unauthenticated network attackers bypass authentication via the vmdirdbcp RPC interface, establishing an administrator session and executing arbitrary commands using the BONESAW Golang exploitation tool.
- **Apache Axis Unsafe Reflection**: Unauthenticated remote attackers exploit crafted HTTP requests accessing unintended controller routes in Confluence Data Center with XML-RPC/SOAP enabled, weaponized to run shell commands, fetch scripts from Pinggy and Cloudflare Tunnel domains, and harvest credentials.
- **Oracle Pre-Authentication Chain**: Attackers chain an Oracle Text bug with a GraphQL interface flaw in Oracle REST Data Services against an exposed web endpoint to execute commands without authentication.
- **Physical Access Lock Screen Bypass (FastUnlock)**: An attacker with physical access to a locked Windows computer uses the built-in Narrator screen reader and recovery options to start programs from the lock screen without signing in, limited to a non-administrator account.

The group deployed BONESAW, SAWSNAKE, CAGEMATCH, BEARBONES, and LAZYBONES tools, SLIMSAVAGE web shells, and conducted Golden SAML attacks to forge tokens and bypass multifactor authentication.
