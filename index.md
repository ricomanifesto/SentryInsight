# Exploitation Report

## Executive Summary

Recent vulnerability disclosures span consumer applications, network infrastructure, and identity systems. A remote code execution flaw in Microsoft Paint (CVE-2026-83844) has been patched through the Microsoft Store, though the fix is not delivered via Windows Update; exploitation has not been observed for this flaw.

Multiple OpenSSH and SonicWall vulnerabilities carry unknown exploitation status despite public disclosure and catalog listings. The SSHole authentication bypass (CVE-2026-123158) affects OpenSSH on musl-based Linux with PAM disabled, while CVE-2026-19868 affects SonicOS SSL-VPN services configured with SAML authentication. Exploitation status for these findings is unknown.

Plex Media Server (Plex2Shell chain), SonicWall SMA1000 and management interface flaws, Brotli, and Veeam Software Appliance vulnerabilities also appear in this reporting window with unknown exploitation status. Defenders should prioritize patching where fixes are available and monitor for further indicators of compromise.

## Active Exploitation Details

### Microsoft Paint Remote Code Execution (CVE-2026-83844)
- **Description**: A remote code execution flaw in Windows Paint, specifically an out-of-bounds read that could let an attacker run code over a network. Microsoft rates it as Important with a CVSS score of 8.1. A successful attack requires no sign-in and no user assistance, though it requires a deep understanding of the target system.
- **Impact**: An attacker could exploit the flaw by sending a specially crafted packet to an affected service over the network, potentially achieving remote code execution without authentication.
- **Status**: The fixed build, 11.2609.401.0, is available through the Microsoft Store only, not through Windows Update. The flaw was not known to be exploited or publicly disclosed when published on October 13, and it was not in the CISA Known Exploited Vulnerabilities catalog when last checked.
- **Severity**: high
- **Exploitation Status**: not_observed
- **Action**: patch
- **CVE IDs**: CVE-2026-83844
- **Reporting**: [The Hacker News — Microsoft Paint RCE Fix Now Available, but Windows Update Won't Deliver It](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: Update Paint through the Store, or let the Store auto-update install the fixed build. In Intune and other device-management tools, the Store app update scan does this across many PCs. Run both check commands again and verify that every copy shows 11.2609.401.0 or later.
- **Vendor Links**: https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83844; https://nvd.nist.gov/vuln/detail/CVE-2026-83844

### OpenSSH SSHole Authentication Bypass (CVE-2026-123158)
- **Description**: An authentication bypass vulnerability in OpenSSH impacting Linux systems that run OpenSSH on the musl C library with Pluggable Authentication Modules (PAM) disabled, including Alpine Linux's default OpenSSH server configuration. An unauthenticated attacker can supply an oversized password (257 to 1,024 bytes) to access accounts configured with an asterisk (*) as the password hash, causing the hash attempt to fail and returning an asterisk that matches the stored value.
- **Impact**: Successful exploitation grants access with the compromised account's existing permissions, potentially enabling access to deployment credentials, application secrets, connected infrastructure, lateral movement, or service disruption.
- **Status**: Addressed in OpenSSH 10.6p2. Previdian observed the first exploitation attempt less than nine hours after CVE publication and confirmed successful root access on a honeypot running Alpine Linux and OpenSSH. Exploitation attempts increased from 8 to 20 from 13 unique IP addresses across multiple countries as of November 8, 2026.
- **Severity**: high
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.
- **Recommended Actions**: Install OpenSSH 10.6p2 or the distribution's patched package, then restart sshd. Investigate "Accepted password for" log entries involving accounts that should not accept password logins. Review doas use and recently created users, files and authorized keys on exposed machines; if a login cannot be ruled out, treat the machine as compromised.
- **Vendor Links**: https://previdian.com/CVE-2026-123158; https://nvd.nist.gov/vuln/detail/cve-2026-123158; https://www.openssh.org/releasenotes.html; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/

## Attack Vectors and Techniques

- **Specially crafted network packet**: Attacker sends a crafted packet to an affected service over the network to achieve remote code execution in Microsoft Paint; requires no sign-in or user assistance.
- **Oversized password authentication bypass**: Attacker submits a password between 257 and 1,024 bytes to authenticate to password-disabled accounts in OpenSSH, causing a failed hash to return an asterisk that matches the stored disabled-account marker.
- **SAML authentication bypass**: Attacker with valid alternate authentication credentials bypasses SAML authentication controls and potentially MFA on SonicOS SSL-VPN services.
- **Unauthenticated management access**: Remote unauthenticated attackers perform unauthorized operations via cross-domain policy and session validation flaws in SonicOS management interfaces.
- **Pre-authentication buffer overflow**: Remote unauthenticated attacker triggers application-level denial-of-service in SonicOS SSL-VPN service.
- **MPTCP remote root execution**: Remote unauthenticated attacker executes commands as root on servers running Multipath TCP listeners via the Linux kernel networking code flaw.
- **AI agent autonomous exploitation**: Autonomous AI agents perform reconnaissance, authentication testing, and exploitation against exposed systems and applications.
