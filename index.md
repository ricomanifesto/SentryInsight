# Exploitation Report

## Executive Summary

Microsoft has released a fix for CVE-2026-83844, a remote code execution flaw in Windows Paint, available through the Microsoft Store rather than Windows Update. The flaw was not known to be exploited when published on October 13, and the scoped assessment marks exploitation status as not observed. The fixed build is 11.2609.401.0, and Paint updates are delivered per-user through Store auto-update rather than enterprise Windows Update channels.

Several recently disclosed vulnerabilities carry unknown exploitation status per the available evidence. OpenSSH flaw CVE-2026-123158 (SSHole) has associated exploitation telemetry, while the Plex2Shell chain affecting QNAP NAS devices—CVE-2026-96652, CVE-2026-96654, CVE-2026-96655, and CVE-2026-96656—has suspected compromise reports and CISA KEV inclusion. SonicWall SSL-VPN flaw CVE-2026-19868 and Veeam Linux kernel flaw CVE-2026-98432 are also recently patched with exploitation evidence still being assessed.

Additional critical issues include Barracuda Email Security Gateway flaws CVE-2026-116606 and CVE-2026-111560, which can be chained for unauthenticated root access, and Brotli flaw CVE-2026-111497. Defenders should prioritize patching for affected products while monitoring for further exploitation indicators.

## Active Exploitation Details

### Microsoft Paint Remote Code Execution (CVE-2026-83844)
- **Description**: A remote code execution flaw in Windows Paint involving an out-of-bounds read that could let an attacker run code over a network. Microsoft rates it as Important with a CVSS score of 8.1, and notes that a successful attack requires a deep understanding of the target system. The fix is distributed through the Microsoft Store build 11.2609.401.0 and is not delivered via Windows Update.
- **Impact**: An attacker could run code over a network with no sign-in and no user assistance by sending a specially crafted packet to an affected service.
- **Status**: Patch available through Microsoft Store; not known to be exploited when published on October 13.
- **Severity**: high
- **Exploitation Status**: not_observed
- **Action**: patch
- **CVE IDs**: CVE-2026-83844
- **Reporting**: [The Hacker News — Microsoft Paint RCE Fix Now Available, but Windows Update Won't Deliver It](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated
- **Recommended Actions**: Update Paint through the Store, or let the Store auto-update install the fixed build. In Intune and other device-management tools, the Store app update scan does this across many PCs. Run both PowerShell commands again and check that every copy shows 11.2609.401.0 or later.
- **Vendor Links**: https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83844; https://nvd.nist.gov/vuln/detail/CVE-2026-83844

### OpenSSH SSHole Authentication Bypass (CVE-2026-123158)
- **Description**: Authentication bypass vulnerability in OpenSSH on systems running the musl C library with Pluggable Authentication Modules (PAM) disabled, including Alpine Linux's default OpenSSH server configuration. An unauthenticated attacker can supply an oversized password between 257 and 1,024 bytes to access accounts configured without usable passwords. The issue stems from a 2016 patch for CVE-2016-6210 and is fixed in OpenSSH 10.6p2.
- **Impact**: Grants access with the compromised account's existing permissions. Attackers may gain access to deployment credentials, application secrets, and connected infrastructure, potentially enabling lateral movement or service disruption.
- **Status**: Patch available in OpenSSH 10.6p2 or distribution patched package; restart sshd required. Exploitation status is unknown.
- **Severity**: high
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.
- **Recommended Actions**: Install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd. Alpine recommends investigating "Accepted password for" log entries involving accounts that should not accept password logins.
- **Vendor Links**: https://www.openssh.org/releasenotes.html; https://nvd.nist.gov/vuln/detail/cve-2026-123158

- **Status**: Patch available via QNAP App Center version 1.43.3.10861 or later. QNAP PSIRT confirmed vulnerabilities exist only in Plex Media Server; QTS, QuTS hero, and other QNAP operating systems are not themselves affected. Exploitation status is unknown.
- **Severity**: unknown
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-96652, CVE-2026-96654, CVE-2026-96655, CVE-2026-96656
- **Reporting**: [Bleeping Computer — QNAP says hackers breaching NAS devices in Plex2Shell attacks](https://www.bleepingcomputer.com/news/security/qnap-says-hackers-breaching-nas-devices-in-plex2shell-attacks/)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: QTS, QuTS hero, and other QNAP operating systems are not themselves affected
- **Recommended Actions**: Update Plex Media Server to the latest version available through the QNAP App Center, currently 1.43.3.10861. Users who do not need remote access should disable related features and stop forwarding port 32400. Those who need remote access should connect via VPN. Treat NAS devices as compromised if running a vulnerable Plex server exposed on the public web; perform a clean reinstall of the OS (QTS or QuTS hero), then reset Plex and NAS credentials.

## Affected Systems and Products

## Attack Vectors and Techniques

- **Network packet injection**: Crafted packets sent over the network to exploit the Windows Paint out-of-bounds read; requires no sign-in and no user assistance
- **Oversized password authentication**: Supplying a password between 257 and 1,024 bytes to OpenSSH to trigger failed password hashing interpreted as successful authentication on accounts with disabled passwords
- **Vulnerability chaining**: Chain of four Plex Media Server vulnerabilities (Plex2Shell) leading to NAS compromise; chain of Barracuda authorization bypass and command injection leading to unauthenticated root access
- **SAML authentication bypass**: Using valid credentials for an alternate authentication method to bypass SAML controls and MFA on SonicWall SSL-VPN
- **Remote root command execution**: Exploiting IPv4 TCP networking code on servers running MPTCP listeners in Veeam-affected Linux kernel components

- **UNC4841**: Exploited Barracuda Email Security Gateway CVE-2023-2868 as a zero-day in 2023 attacks; unrelated to the November 2026 Barracuda flaws
