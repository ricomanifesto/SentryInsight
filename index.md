# Exploitation Report

## Executive Summary

Multiple critical vulnerabilities across consumer, enterprise, and infrastructure products have been recently patched or are under active assessment. Microsoft has released a fix for CVE-2026-83844, a remote code execution flaw in Windows Paint, available through the Microsoft Store rather than Windows Update; exploitation has not been observed. OpenSSH flaw CVE-2026-123158 (SSHole) and the Plex2Shell chain (CVE-2026-96652, CVE-2026-96654, CVE-2026-96655, CVE-2026-96656) are associated with reported exploitation activity, though the scoped assessments classify their status as unknown.

SonicWall disclosed CVE-2026-19868, an SSL-VPN SAML authentication bypass with CVSS 7.1, and CVE-2026-102255, a maximum-severity flaw affecting SMA1000 appliances, alongside historical Barracuda Email Security Gateway flaws including CVE-2023-2868 and newly chained flaws CVE-2026-116606 and CVE-2026-111560 that can yield root access without login. Veeam disclosed CVE-2026-98432, a critical Linux kernel flaw allowing remote unauthenticated root access on MPTCP listeners. AI-assisted attack activity is also prominent, with ARTEX-linked actors and autonomous agents observed targeting multiple organizations and platforms.

Threat activity spans financially motivated intrusion, espionage, and AI-assisted exploitation. Security firms and vendors including Previdian, QNAP, SonicWall, and Microsoft have reported exploitation attempts or confirmed access on honeypots and customer systems. Defenders should prioritize patching for Paint, OpenSSH, Plex Media Server, SonicWall, Barracuda, and Veeam components while monitoring for AI-driven reconnaissance and credential theft campaigns.

### CVE-2026-83844: Microsoft Paint Remote Code Execution Flaw
- **Description**: CVE-2026-83844 is an out-of-bounds read flaw in Windows Paint that could let an attacker run code over a network by sending a specially crafted packet to an affected service. The attack requires no sign-in and no user assistance, though Microsoft states a successful attack requires a deep understanding of the target system.
- **Impact**: Remote code execution on affected Windows Paint installations.
- **Status**: The fixed build is 11.2609.401.0, delivered through the Microsoft Store rather than Windows Update. The flaw was not known to be exploited or publicly disclosed when Microsoft published it on October 13, and it was not in CISA's Known Exploited Vulnerabilities catalog when checked.
- **Severity**: high
- **Exploitation Status**: not_observed
- **Action**: patch
- **CVE IDs**: CVE-2026-83844
- **Reporting**: [The Hacker News — Microsoft Paint RCE Fix Now Available, but Windows Update Won't Deliver It](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: Update Paint through the Store, or let the Store auto-update install the fixed build. In Intune and other device-management tools, the Store app update scan does this across many PCs. Run both commands again and check that every copy shows 11.2609.401.0 or later.; The advisory lists no workaround or mitigation. Before the fix reached the Store, Vitko suggested removing Paint where nobody needs it, for every user and from the provisioned copy. He did not test that step.

### CVE-2026-123158: OpenSSH SSHole Authentication Bypass
- **Description**: CVE-2026-123158, codenamed SSHole, impacts Linux systems running OpenSSH on the musl C library with Pluggable Authentication Modules (PAM) disabled, including Alpine Linux's default OpenSSH server configuration. An unauthenticated attacker can supply an oversized password between 257 and 1,024 bytes to access accounts configured with an asterisk (*) as the password hash, causing failed password hashing to be interpreted as successful authentication. The issue traces to a 2016 patch for CVE-2016-6210.
- **Impact**: Unauthorized SSH access to password-disabled accounts with the compromised account's existing permissions; potential access to deployment credentials, application secrets, lateral movement, or service disruption.
- **Status**: Addressed in OpenSSH 10.6p2. Exploitation status per scoped assessment: unknown. Previdian observed exploitation attempts less than nine hours after CVE publication and confirmed successful root access on an Alpine Linux honeypot; telemetry shows eight attempts from IP 89.116.89[.]18 geolocated to Japan.
- **Severity**: high
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.
- **Recommended Actions**: Install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd.; Alpine is also recommending that users investigate "Accepted password for" log entries involving accounts that should not accept password logins. "Look in /var/log/messages for sshd lines reading Accepted password for an account that has no password (alpine, root, or any key-only user)," Alpine said. "Review doas use and recently created users, files and authorized keys on exposed machines. If you cannot rule out a login, treat the machine as compromised."
- **Vendor Links**: https://previdian.com/CVE-2026-123158; https://nvd.nist.gov/vuln/detail/cve-2026-123158; https://www.openssh.org/releasenotes.html; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/

## Attack Vectors and Techniques

- **Specially crafted network packet**: An attacker can exploit CVE-2026-83844 by sending a specially crafted packet to an affected service over the network, requiring no sign-in or user assistance.
- **Oversized password authentication bypass**: In CVE-2026-123158, an unauthenticated attacker supplies an oversized password (257-1,024 bytes) to trigger failed password hashing, which is mistakenly interpreted as successful authentication on accounts with an asterisk password hash.
- **Chained authorization bypass and command injection**: CVE-2026-116606 and CVE-2026-111560 are chained so an unauthenticated attacker restores a crafted backup, gaining administrator access that enables root command injection via a forged checksum.
- **SAML authentication bypass**: CVE-2026-19868 allows attackers with valid alternate credentials to bypass SAML authentication controls, potentially including SAML-enforced MFA on SonicWall SSL-VPN.
- **MPTCP listener exploitation**: CVE-2026-98432 allows remote unauthenticated attackers to execute commands as root on servers running Multipath TCP listeners through the IPv4 TCP networking code.
- **Autonomous AI agent exploitation**: ARTEX and similar agentic frameworks automate reconnaissance and exploitation, scanning for exposed secrets and conducting follow-on attacks with minimal hands-on-keyboard interaction.
- **Browser extension script injection via Claude Dispatch**: A malicious or compromised browser extension running on claude.ai can send instructions to Claude Desktop, causing it to execute commands such as npm install on the local computer.
