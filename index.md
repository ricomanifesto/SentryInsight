# Exploitation Report

## Executive Summary

Recent exploitation activity centers on several recently patched vulnerabilities added to or assessed alongside CISA's Known Exploited Vulnerabilities catalog. CISA added CVE-2026-134624, a server-side request forgery in N-able MailAssure, and CVE-2026-133968, a path traversal in MONAI Label potentially leading to remote code execution; the latter has been linked to an agentic attack in which a suspected China-nexus threat actor used AI-powered tooling to exploit a zero-day. Broadcom also shipped patches for multiple VMware vCenter flaws, including critical authentication bypass CVE-2026-123903 (CVSS 9.8) and arbitrary file write CVE-2026-123904, following a prior zero-day, CVE-2026-123890, exploited by a suspected China-nexus group tracked as Armory Castle. WHMCS patched three SQL injection flaws, including unauthenticated CVE-2026-82981.

Beyond these, a .NET Framework code-integrity bypass (CVE-2026-108398) and a VirtualBox process-hardening bypass (CVE-2026-87268) were disclosed after patches shipped, and Microsoft addressed an Azure API Management Classic access-path issue tied to credential theft targeting energy companies. Separately, threat activity includes the Inception vishing campaign tied to cluster O-UNC-053, Webworm's modified SoftEther VPN tooling, and Iran-aligned Volant Manticore operations using an IPFS-based backdoor.

Per the supplied exploitation assessments, the exploitation status of the CVE findings in this report is assessed as unknown or potential rather than confirmed active exploitation; none of the findings should be read as source-confirmed active exploitation unless the Exploitation Status field states otherwise.

## Affected Systems and Products

- **VMware vCenter, VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform**: Directory service (vmdir) authentication bypass, arbitrary file write, and denial-of-service flaws across 9.1.x, 9.0.x, vCenter 8.0, vCenter 7.0, and 5.x product lines; fixed releases include 9.1.2, 9.0.2.0300, 8.0 U3m, and 5.2.5.

- **.NET Framework and Windows**: .NET Framework version 4 loading path on Windows, including Windows 11 S Mode with UMCI enforced.
- **Oracle VirtualBox**: VirtualBox 7.2.16 on Windows hosts; fixed in September build 7.2.18.
- **N-able MailAssure / SpamExperts Hosted Cloud**: LDAP synchronization connection check component; service disruption occurred November 16, 2026, with functionality restored by November 21, 2026.
- **MONAI Label**: Open-source medical imaging AI application; targeted in an agentic campaign against East Asian university IP addresses.
- **Azure API Management Classic tiers**: Unauthenticated access path to management functionality and secrets; v2 tiers are not affected.

## Attack Vectors and Techniques

- **Authentication bypass**: Network access to VMware Directory Service (vmdir) used to bypass authentication and access vCenter without valid credentials.
- **Arbitrary file write**: Processing of certain archives in vCenter to write files and achieve code execution on the appliance.
- **SQL injection**: Unauthenticated and authenticated injection in WHMCS shopping cart and Client Area to extract database records and password hashes.
- **Email campaign file disclosure**: Client-supplied data in WHMCS email campaigns used to read server configuration files and execute code.
- **.NET loading-path bypass**: Clearing the IMAGE_FILE_EXECUTABLE_IMAGE flag in a .NET header to bypass image checks while .NET still loads the file, combined with COM hijacking to run code inside protected processes.
- **VirtualBox hardening bypass**: .NET AnyCPU files loaded through an uninspected fallback path to bypass VirtualBox process hardening on Windows hosts.
- **SSRF**: Authenticated API abuse in N-able MailAssure LDAP sync to connect to arbitrary internal hosts and ports.
- **Path traversal**: Unauthenticated remote file write outside the intended datastore in MONAI Label leading to potential remote code execution.
- **Vishing / SSO phishing**: Phone-based social engineering targeting single sign-on credentials via legal-themed phishing domains imitating Okta and NetIQ/OpenText Access Manager.
- **Modified dual-use tool**: Rebuilt SoftEther VPN Bridge with altered watermarks, endpoints, and configuration to evade detection while maintaining covert remote access.
- **IPFS-based C2**: KuboShell backdoor using IPFS and Pinata for command-and-control and file transfer in espionage campaigns.

## Threat Actor Activities

- **Inception / O-UNC-053**: Newly formed data extortion group operating since late October 2026, running a large-scale vishing campaign targeting SSO credentials of global brands; Okta links the cluster to former ShinyHunters activity (O-UNC-053) active since March 2026, while Inception denies affiliation. Targets include technology, healthcare, financial services, retail, hospitality, and legal sectors using legal-themed domains.
- **ShinyHunters**: Extortion gang claiming return on a new Tor leak site on November 23, 2026, following law enforcement arrests; operators signed messages with historical PGP keys, though key circulation prevents certainty about identity continuity. Previously claimed FBI systems breach via an Oracle PeopleSoft vulnerability in September 2026.
- **Armory Castle**: Suspected China-nexus cyber espionage group that exploited VMware Directory Service flaw CVE-2026-123890 as a zero-day; Broadcom notes CVE-2026-123903 is distinct and unrelated.
- **Suspected China-nexus actor (CAIRN)**: Conducted an approximately 48-hour agentic attack beginning September 8, 2026, targeting East Asian university IP addresses, exploiting MONAI Label CVE-2026-133968 in about 11 minutes to write arbitrary files and deploy a Python reverse shell as root.
- **Webworm**: China-aligned nation-state group using a modified SoftEther VPN Bridge (vpnbridge_x64.exe version 4.44, build 9807), rebranded as NtMonitor VPN, with altered HTTP endpoints and PNG watermarks to evade detection while establishing covert remote access.
- **Volant Manticore**: Iran-aligned cyber espionage group, likely former MuddyWater operators, targeting telecommunications, airlines, and critical infrastructure in Cyprus and Saudi Arabian healthcare entities using the KuboShell IPFS backdoor and Homa framework since late August 2025.
- **AI-driven offensive frameworks**: ARTEX, CAIRN, AntiFox, and CyberStrikeAI used in recent campaigns; ARTEX activity included credential theft for AI model access and cryptocurrency exchange KYC bypass using deepfake injection, with AWS MadPot sensor detections and Previdian telemetry recording ARTEX-marked requests against Oracle WebLogic, Langflow, and Flowise.
