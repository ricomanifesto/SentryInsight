# Exploitation Report

## Executive Summary

Multiple critical vulnerabilities are under active or potential exploitation across enterprise and infrastructure products. Drupal core installer flaw CVE-2026-132165 has been added to CISA's Known Exploited Vulnerabilities catalog with exploitation reported on live sites, while GeoServer flaws including CVE-2026-129245 and CVE-2026-120705 are being probed in the wild. Separately, a CVSS 10.0 remote code execution flaw in Hex.pm (CVE-2026-129514) was exploited against package registry servers, and a WordPress supply chain incident involving backdoored WP Connect plugins (CVE-2026-135202) was blocked before public release.

Additional critical flaws with exploitation evidence include PHP2Shell vulnerabilities (CVE-2026-109618 and CVE-2026-109619) chained with the Fragnesia Linux kernel flaw (CVE-2026-46300) against network appliances, Vates Xen Orchestra authentication bypass (CVE-2026-133469), HPE Juniper Session Smart command injection (CVE-2026-103406), and Rejetto HFS exploitation (CVE-2026-61500). Threat actor activity spans Iranian IRGC-linked units targeting refrigeration controllers, unknown AI-driven actors compromising Check Point management servers, and Com-affiliated vishing campaigns against cloud environments. Affected version details are not available from the supplied scoped evidence for CVE-specific findings.

## Active Exploitation Details

### Drupal Core Installer Remote Code Execution (CVE-2026-132165)
- **Description**: A critical vulnerability in Drupal core's installer (install.php) allows anonymous users to gain remote code execution or take over vulnerable sites by bypassing installation checks through server resource exhaustion.
- **Impact**: Attackers can hijack unpatched Drupal sites, execute arbitrary PHP code, and achieve complete site takeover on affected installations.
- **Status**: Exploitation status is potential. CISA added the vulnerability to its KEV catalog; exploitation was reported on live sites as early as 2026-11-19 19:00 UTC. Patches are available in Drupal 11.4.13, 11.3.22, 10.6.22 and later versions.
- **Severity**: critical
- **Exploitation Status**: potential
- **Action**: patch
- **CVE IDs**: CVE-2026-132165
- **Reporting**: [Bleeping Computer — Hackers now exploit critical Drupal RCE flaw to hijack sites](https://www.bleepingcomputer.com/news/security/hackers-now-exploit-critical-drupal-rce-flaw-to-hijack-sites/), [The Hacker News — Drupal Fail2Install Exploit Details Emerge as Critical RCE Flaw Faces Active Exploitation](https://thehackernews.com/2026/11/drupal-fail2install-exploit-details.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Site owners who have already secured the installer ("install.php") are not impacted.
- **Recommended Actions**: Websites using the paid Drupal Steward Web Application Firewall (WAF) service are already protected from known attack vectors, but admins are still advised to upgrade to the latest available Drupal version in case other attack vectors are discovered.; Those who can't immediately upgrade should block access to /core/install.php in the web server configuration or the .htaccess file in the web root to secure the Drupal installer.; After updating to the latest supported versions, it's recommended to run "update.php" to fix existing production sites in this state and secure the Drupal installer on all new and existing sites.
- **Vendor Links**: https://www.drupal.org/sa-core-2026-017; https://www.cisa.gov/news-events/alerts/2026/11/24/cisa-adds-three-known-exploited-vulnerabilities-catalog; https://www.cisa.gov/known-exploited-vulnerabilities-catalog

### Hex.pm Server Remote Code Execution (CVE-2026-129514)
- **Description**: A parser vulnerability in Hex.pm's request body handling allowed unauthenticated remote code execution via crafted Erlang terms containing __struct__ keys that bypassed safety checks.
- **Impact**: Attackers ran operating system commands with the registry service account's privileges on six production servers; potential access to account data including email addresses, password hashes, and two-factor authentication secrets could not be ruled out.
- **Status**: Exploitation status is unknown. Exploitation occurred via 69 requests from two addresses on Monday; all servers were patched within about 15 minutes of the first malicious request. Exploitation before Monday has not been established.
- **Severity**: critical
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-129514
- **Reporting**: [The Hacker News — Hackers Exploited CVSS 10.0 Hex.pm RCE Flaw to Compromise 6 Package Registry Servers](https://thehackernews.com/2026/11/hackers-exploited-cvss-100-hexpm-rce.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: Everyone with a hex.pm account has been logged out; change your hex.pm password, reset two-factor authentication by setting up a new authenticator entry, and store the new recovery codes.; Until the new client ships, the advice is to fetch packages only from repo.hex.pm and to avoid third-party mirrors.
- **Vendor Links**: https://hex.pm/blog/security-incident-on-hexpm; https://github.com/hexpm/hexpm/security/advisories/GHSA-9pmm-hf4r-27pg

## Attack Vectors and Techniques
- **Drupal Installer Abuse**: Exploiting install.php through server resource exhaustion (EMFILE, database connection exhaustion, TCP source-port exhaustion) to trick Drupal into believing a site is not installed, leading to pre-authentication RCE via SQLite database containing PHP code
- **GeoServer WFS Exploitation**: Unauthenticated WFS requests for arbitrary file read, service security rule bypass via prefixed service names (x/WFS), stored query path disclosure, and XML injection
- **PHP Deserialization / Struct Injection**: Crafted Erlang terms with __struct__ keys that bypass parser safety checks, leading to remote code execution through error reporting and database library inspection
- **Supply Chain Compromise**: Backdoored plugin versions pushed through a compromised developer WordPress.org account; malicious code loaded via remote-control module on every request
- **Authentication Bypass**: Hard-coded signing keys ("geoserver") for remember-me cookie forgery; empty JSON object tokens for Xen Orchestra administrative access
- **Command Injection**: Specially crafted salt minion IDs in Juniper Session Smart products enabling root command execution
- **PHP2Shell Chaining**: PHP vulnerabilities chained with Linux kernel XFRM ESP-in-TCP flaw (Fragnesia) to deploy PHP webshells and execute commands as root
- **Privilege Escalation**: Local low-privilege escalation to root via Linux kernel XFRM subsystem vulnerability
- **Automated Exploitation Pipeline**: AI-driven scanning and exploitation using disposable IP infrastructure, Nmap, Chisel, Impacket, and Python scripts for reconnaissance and lateral movement
