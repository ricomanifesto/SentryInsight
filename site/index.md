# Exploitation Report

## Executive Summary

Active exploitation has been confirmed for CVE-2026-90436, an unsafe reflection vulnerability in Apache Axis 1.x that allows unauthenticated remote code execution. Rapid7 detected exploitation against Atlassian Confluence Data Center, and CISA added the flaw to its Known Exploited Vulnerabilities catalog. Axis 1 has reached end-of-life and remains unpatched, requiring migration to Apache Axis 2/Java or a patched build as the only supported remediation.

A VMware vCenter Server authentication bypass, CVE-2026-123890, was exploited by the suspected Chinese state-sponsored group Armory Castle (formerly UNC5221) beginning in early September 2026, though the supplied exploitation assessment rates its status as unknown. Broadcom has released patches in VMSA-2026-0009 but has not confirmed exploitation. The same intrusion campaign also leveraged the BeyondTrust Remote Support zero-day CVE-2026-102764 since late August.

Additional critical patches address NGINX HTTP/2 flaws (CVE-2026-123007 and CVE-2026-123633), LiteLLM (CVE-2026-40217), REDCap (CVE-2026-90817), and Synology DSM (CVE-2024-10441). Exploitation status for these is assessed as unknown in the supplied evidence, with patches available where vendors have issued fixes. Affected version details for several findings are constrained by scoped reference evidence and are not emitted as version IDs in this report.

## Active Exploitation Details

### CVE-2026-90436 Apache Axis unsafe reflection remote code execution vulnerability
- **Description**: An unsafe reflection vulnerability in Apache Axis allows an unauthenticated remote attacker to execute arbitrary code via crafted HTTP requests accessing unintended controller routes through XML-RPC and SOAP APIs.
- **Impact**: Attackers achieved remote code execution on Atlassian Confluence Data Center, ran shell commands and scripts, queried databases, harvested credentials, and attempted AS-REP Roasting; the flaw was also exploited alongside 4EverAble2Shell vulnerabilities to deploy cryptocurrency miners.
- **Status**: Active exploitation detected by Rapid7 and added to the CISA KEV catalog; Axis 1.x has reached end-of-life and remains unpatched.
- **Severity**: critical
- **Exploitation Status**: active
- **Action**: mitigate
- **CVE IDs**: CVE-2026-90436
- **Reporting**: [The Hacker News — CISA Warns of 4 Exploited Flaws Linked to Ransomware, Cryptomining, and LLMjacking Attacks](https://thehackernews.com/2026/11/cisa-warns-of-4-exploited-flaws-linked.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: CVE-2026-90436, which affects Axis 1.x versions, remains unpatched as Axis 1 has reached end-of-life (EoL) status. It's recommended to migrate to a different SOAP engine, such as Apache Axis 2/Java. Alternatively, users can use a build of Axis with the patch from a July 12, 2026, commit applied.
- **Vendor Links**: https://www.cisa.gov/news-events/alerts/2026/11/18/cisa-adds-four-known-exploited-vulnerabilities-catalog; https://www.cisa.gov/known-exploited-vulnerabilities-catalog; https://www.cve.org/CVERecord?id=CVE-2026-90436; https://confluence.atlassian.com/security/cve-2026-90436-remote-code-execution-in-confluence-data-center-1874560038.html; https://www.rapid7.com/blog/post/etr-rapid7-detected-exploitation-of-cve-2026-90436-against-atlassian-confluence-data-center-n-able-n-central-also-exploited/; https://lists.apache.org/thread/8slf0j9gz35z56t0glt5h0ncwlbn4bdz; https://github.com/apache/axis-axis1-java/commit/41f3b4e8d04e310ca81f86b92630ab2c11d608bd

### CVE-2026-123890 VMware vCenter authentication bypass vulnerability
- **Description**: An authentication bypass vulnerability in the VMware Directory Service allows an unauthenticated attacker with network access to bypass authentication and gain unauthorized access to vCenter Server.
- **Impact**: Successful exploitation results in a remote authentication bypass creating an authenticated session as administrator@vsphere.local, enabling arbitrary command execution, file acquisition including the data.mdb database, SAML signing key extraction, and Golden SAML attacks.
- **Status**: Exploitation status is unknown per the supplied assessment; Broadcom has not confirmed exploitation, while Mandiant documented attacks exploiting the flaw by Armory Castle in early September 2026. Patches are available in VMSA-2026-0009.
- **Severity**: critical
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123890
- **Reporting**: [Bleeping Computer — VMware patches vCenter zero-day exploited in attacks since September](https://www.bleepingcomputer.com/news/security/vmware-patches-vcenter-zero-day-exploited-in-attacks-since-september/), [The Hacker News — Critical VMware vCenter Flaw (CVSS 9.8) Lets Network Attackers Bypass Authentication](https://thehackernews.com/2026/11/critical-vmware-vcenter-flaw-cvss-98.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: ESX itself is not affected; none of the five flaws in the advisory lets code run on an ESX host from inside a virtual machine.
- **Recommended Actions**: The company considers the vCenter vulnerability as an emergency update, urging organizations to install the patches as soon as possible; Broadcom says there are no official workarounds for the vulnerabilities, although network restrictions and firewall controls can help reduce exposure; the researchers urge admins to apply the VMware security updates as soon as possible and configure additional security controls to protect their virtualization infrastructure against future attacks.

### CVE-2026-123633 NGINX HTTP/2 use-after-free vulnerability

- **Status**: Exploitation status is unknown per the supplied assessment; Wiz demonstrated remote code execution but is not publicly releasing its proof-of-concept exploits. Flaws are fixed in NGINX Open Source 1.30.7 stable and 1.31.9 mainline.
- **Severity**: unknown

- **CVE IDs**: CVE-2026-123633

## Attack Vectors and Techniques

- **Unsafe reflection in Apache Axis**: Crafted HTTP requests access unintended controller routes from a public context, supplying crafted file-path or stream parameters during data import processing; Confluence instances with Remote API (XML-RPC & SOAP) enabled are vulnerable
- **VMware Directory Service authentication bypass**: Custom Golang exploitation tool BONESAW targets the vmdirdbcp RPC interface to create vCenter SSO administrator accounts, steal directory databases, extract SAML signing keys, and forge authentication tokens
- **REDCap code injection**: Crafted HTTP requests with file-path or stream parameters during data import processing using a valid public survey hash
- **LiteLLM unprotected alternate channel**: Bytecode rewriting at the /guardrails/test_custom_code URI to elevate limited-access inference keys into full administrative credentials
- **Synology DSM improper encoding**: Remote arbitrary code execution via unspecified vectors on NAS devices, resulting in C3RB3R ransomware deployment
- **NGINX HTTP/2 memory corruption**: Flow-control bugs and use-after-free conditions triggered via HTTP/2 connections; root access achievable by chaining with a separate Linux kernel SCTP subsystem flaw to escape Docker containers

## Threat Actor Activities

- **Armory Castle (formerly UNC5221)**: Suspected Chinese state-sponsored cyberespionage group exploited CVE-2026-123890 in early September 2026 and CVE-2026-102764 since late August 2026; deployed BONESAW, SAWSNAKE, SLIMSAVAGE, CAGEMATCH, BEARBONES, and LAZYBONES to maintain persistence, escalate privileges, and steal credentials from VMware environments
- **Unknown threat actors**: Exploited CVE-2026-90436 against Atlassian Confluence Data Center in a customer environment on November 13, 2026, deploying cryptocurrency miners, harvesting credentials, querying production cloud data warehouses, and signing into Microsoft 365 using legacy authentication
- **Unknown threat actors**: Leveraged CVE-2026-40217 in LLMjacking attacks to elevate inference keys to administrative credentials and establish persistence across financial services, retail, transportation, and technology organizations in North America, South America, and the Asia Pacific region
