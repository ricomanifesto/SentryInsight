# Exploitation Report

## Executive Summary

Threat actors are actively targeting multiple recently patched and unpatched vulnerabilities across infrastructure, content management, and collaboration platforms. GeoServer flaws including arbitrary file read and authorization bypass issues have been linked to in-the-wild exploitation probes and honeypot observations, while a separate hard-coded signing key flaw presents potential chaining risk for unauthenticated remote code execution. Drupal core weaknesses involving the installer and resource exhaustion bypasses have been added to CISA’s Known Exploited Vulnerabilities catalog, with remediation available for supported branches but no fix for end-of-life versions.

Critical flaws in Mitel MiCollab, Vates Xen Orchestra, and HPE Juniper Session Smart products have been exploited or reported as exploited in the wild, with evidence of web shell deployment, credential harvesting, and rapid lateral movement against victim organizations. Danfoss refrigeration controllers remain unpatched for a stack-based buffer overflow that allows unauthenticated remote code execution, and administrative guidance focuses on network segregation and VPN restrictions pending a future software release. Additional chains involving PHP2Shell and Fragnesia have been observed targeting Palo Alto Networks and Check Point firewalls.

Exploitation status across the cited vulnerabilities is predominantly unknown or potential based on the supplied evidence, and no finding in this report should be read as confirmed active exploitation unless the specific finding’s status field states otherwise. Defenders should prioritize patching where updates are available and apply network mitigations where vendor fixes are not yet released.

## Active Exploitation Details

### Drupal Core Fail2Install Remote Code Execution (CVE-2026-132165)
- **Description**: A not-failing-securely vulnerability in Drupal core allows an unauthenticated attacker to take over an existing site or execute arbitrary code via the Drupal installer under specific conditions.
- **Impact**: Attackers can bypass installation checks by exhausting server resources, create an administrator-controlled account, and execute arbitrary PHP code through an SQLite database with a PHP extension.
- **Status**: Exploitation status is unknown. Patches are available for Drupal 11.4.14, 11.3.23, and 10.6.23; no fix exists for Drupal 11.0.x to 11.2.x or 10.5.x and below (end-of-life).
- **Severity**: critical
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-132165
- **Reporting**: [The Hacker News — Drupal Fail2Install Exploit Details Emerge as Critical RCE Flaw Faces Active Exploitation](https://thehackernews.com/2026/11/drupal-fail2install-exploit-details.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Site owners who have already secured the installer ("install.php") are not impacted.
- **Recommended Actions**: After updating to the latest supported versions, it's recommended to run "update.php" to fix existing production sites in this state and secure the Drupal installer on all new and existing sites.
- **Vendor Links**: https://www.drupal.org/sa-core-2026-017; https://www.cisa.gov/news-events/alerts/2026/11/24/cisa-adds-three-known-exploited-vulnerabilities-catalog

## Attack Vectors and Techniques

- **Unauthenticated WFS GetFeatureById XML injection**: Attackers send a single unauthenticated Web Feature Service request to read local files or fetch adversary-controlled URLs via GeoServer
- **Service security rules bypass**: Prefixing the Web Feature Service name (x/WFS) slips past admin-only rules for stored queries, enabling unauthorized OWS operations
- **Administrator session forgery**: Use of a predictable hard-coded signing key to forge valid administrator authentication cookies without knowing the administrator password
- **Resource exhaustion bypass**: Abusing server resource limits (EMFILE, database connection exhaustion, TCP source-port exhaustion) to trick Drupal into believing a site is not installed, reopening the installer on an existing website
- **SQLite PHP payload execution**: Selecting a .php path during Drupal SQLite database installation so PHP code submitted as the website name is written into an executable database file
- **Command injection via salt minion ID**: Remote attackers execute arbitrary commands as root through specially crafted salt minion IDs in Juniper Session Smart products
- **Empty JSON object authentication bypass**: Specially crafted authentication tokens with empty JSON objects bypass authentication and grant administrative privileges in Xen Orchestra
- **PHP web worker remote code execution**: Chaining PHP2Shell vulnerabilities (CVE-2026-109618 and CVE-2026-109619) to run code remotely, then escalating via Fragnesia (CVE-2026-46300) to root on exposed firewall management interfaces
- **Stored query validation probes**: Attackers create and invoke stored queries on GeoServer machines, verify their creation, and delete them to validate vulnerability before deeper exploitation
