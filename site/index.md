# Exploitation Report

## Executive Summary

Recent exploitation activity includes confirmed attacks on OpenSSH through the SSHole authentication bypass, with threat actors achieving root access on honeypots within hours of disclosure. The Plex2Shell vulnerability chain targeting QNAP NAS devices has been added to CISA's Known Exploited Vulnerabilities catalog, and SonicWall SSL-VPN appliances are under active attack with CISA confirming exploitation in the wild. State-sponsored group APT29 continues watering-hole campaigns against mobile users, while AI-driven threats and phishing platforms expand credential theft operations.

Several recently patched vulnerabilities have not yet been observed in exploitation. Microsoft Paint remote code execution flaw CVE-2026-83844 is fixed in Store build 11.2609.401.0, though Windows Update does not deliver the update. OpenSSH username enumeration flaw CVE-2016-6210 underlies the newer SSHole issue but is presented as historical context. Multiple additional vulnerabilities, including Barracuda Email Security Gateway flaws and a Linux kernel MPTCP flaw, have unknown exploitation status based on available evidence.

AI is increasingly involved in both offensive and defensive security operations. Autonomous agents have been linked to breaches at WorkOS and Chainalysis, phishing-as-a-service platforms are stealing Microsoft and Google credentials through fake AI events, and Chinese cyber-espionage group Vapor Panda used the ARTEX framework against approximately 200 organizations. Critical infrastructure sectors including refrigeration and cold-chain systems are also facing active targeting by FBI- and CISA-warned actors.

## Active Exploitation Details

### Microsoft Paint Remote Code Execution (CVE-2026-83844)
- **Description**: An out-of-bounds read remote code execution flaw in Windows Paint that could let an attacker run code over a network by sending a specially crafted packet to an affected service. The attack requires no sign-in and no user assistance, though Microsoft notes a successful attack requires a deep understanding of the target system.
- **Impact**: Attackers could achieve remote code execution on affected Windows systems running vulnerable Paint builds.
- **Status**: A fix is available in Microsoft Store build 11.2609.401.0, delivered through Store updates rather than Windows Update. The flaw was not known to be exploited or publicly disclosed when published on October 13. The CVE record lists Paint as affected only below 11.2605.91.0.
- **Severity**: high
- **Exploitation Status**: not_observed
- **Action**: patch
- **CVE IDs**: CVE-2026-83844
- **Reporting**: [The Hacker News — Microsoft Paint RCE Fix Now Available, but Windows Update Won't Deliver It](https://thehackernews.com/2026/11/microsoft-paint-rce-fix-now-available.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: "Update Paint through the Store, or let the Store auto-update install the fixed build. In Intune and other device-management tools, the Store app update scan does this across many PCs. Run both commands again and check that every copy shows 11.2609.401.0 or later."
- **Vendor Links**: https://msrc.microsoft.com/update-guide/vulnerability/CVE-2026-83844; https://nvd.nist.gov/vuln/detail/CVE-2026-83844

### OpenSSH SSHole Authentication Bypass (CVE-2026-123158)
- **Description**: An authentication bypass flaw in OpenSSH on Linux systems running the musl C library with Pluggable Authentication Modules (PAM) disabled, including Alpine Linux's default OpenSSH server configuration. An unauthenticated attacker supplies an oversized password between 257 and 1,024 bytes to accounts with disabled passwords, causing failed password hashing to return an asterisk that matches the stored disabled-password marker, resulting in successful authentication.
- **Impact**: Unauthorized SSH access with the compromised account's existing permissions; potential access to deployment credentials, application secrets, lateral movement, or service disruption.
- **Status**: Addressed in OpenSSH 10.6p2. Previdian observed the first exploitation attempt less than nine hours after CVE publication and confirmed successful root access on an Alpine Linux honeypot. Telemetry showed eight exploitation attempts from IP address 89.116.89[.]18 geolocated to Japan.
- **Severity**: high
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.
- **Recommended Actions**: "Affected users are advised to install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd. Alpine is also recommending that users investigate 'Accepted password for' log entries involving accounts that should not accept password logins. 'Look in /var/log/messages for sshd lines reading Accepted password for an account that has no password (alpine, root, or any key-only user),' Alpine said. 'Review doas use and recently created users, files and authorized keys on exposed machines. If you cannot rule out a login, treat the machine as compromised.'"
- **Vendor Links**: https://nvd.nist.gov/vuln/detail/cve-2026-123158; https://www.openssh.org/releasenotes.html; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/

- **Windows Paint**: Vulnerable Paint builds on Windows systems; fixed build 11.2609.401.0 delivered via Microsoft Store, not Windows Update.
- **OpenSSH**: Linux systems running OpenSSH on the musl C library with PAM disabled, including Alpine Linux's default OpenSSH server configuration. Not affected: Dropbear, glibc-based Linux distributions, non-Linux systems, PAM-enabled systems.
- **Plex Media Server**: QNAP NAS devices running Plex Media Server; fixed in version 1.43.3.10861 through QNAP App Center. QTS, QuTS hero, and other QNAP operating systems are not themselves affected.
- **SonicWall SonicOS**: Gen7 versions 7.3.3-7015 and earlier and Gen8 versions 8.2.2-8015 and earlier; fixed in versions 7.3.4-7013 and 8.2.3-8015. SonicWall firewalls with SSL-VPN services configured for SAML authentication are affected by CVE-2026-19868.
- **Barracuda Email Security Gateway**: Email Security Gateway appliances; fixed in version 9.4.0.030 and later. Five other Barracuda products are reachable by the command injection but require administrator access.
- **Linux Kernel**: Servers running Multipath TCP (MPTCP) listeners; Veeam Software Appliance components impacted by CVE-2026-98432.
- **Brotli**: Systems using the Brotli compression library.

## Attack Vectors and Techniques

- **Specially crafted network packet**: An attacker sends a specially crafted packet to an affected service over the network; requires no sign-in and no user assistance (Microsoft Paint RCE).
- **Oversized password authentication**: Attacker supplies a password between 257 and 1,024 bytes to password-disabled accounts, causing failed hashing to return an asterisk that matches the disabled-password marker, enabling authentication (OpenSSH SSHole).
- **Vulnerability chain**: Chaining an authorization bypass to restore a crafted configuration backup with a command injection that runs as root, achieving root access with no login (Barracuda Email Security Gateway).
- **Plex2Shell chain**: Chain of four Plex Media Server vulnerabilities exploited to compromise QNAP NAS devices; exploitation began after technical details became public on October 16.
- **SAML authentication bypass**: Attackers with valid credentials for an alternate authentication method bypass SAML authentication controls, potentially including SAML-enforced MFA, on SonicWall SSL-VPN services (CVE-2026-19868).
- **MPTCP listener exploitation**: Remote unauthenticated attackers execute commands as root on servers running Multipath TCP listeners via IPv4 TCP networking code (CVE-2026-98432).
- **Phishing-as-a-service**: Kali365 conducts Microsoft device code phishing; VoidProxy acts as an adversary-in-the-middle reverse proxy to intercept Google sign-ins and steal authentication session cookies; both platforms bypass multifactor authentication by capturing authenticated sessions.

## Threat Actor Activities

- **APT29 (Russian state-sponsored)**: Conducts watering-hole campaigns targeting thousands of mobile users; after compromising websites, the group fingerprints victims and harvests information from interesting targets.
- **Unknown operators (IP 89.116.89[.]18)**: Observed exploiting OpenSSH SSHole less than nine hours after CVE publication; confirmed successful root access on an Alpine Linux honeypot; ran reconnaissance commands including id, uname, and hostname through non-interactive SSH sessions.
- **UNC4841**: Exploited Barracuda Email Security Gateway CVE-2023-2868 as a zero-day in 2023 attacks; unrelated to current Barracuda flaws.
- **Vapor Panda (Chinese cyber-espionage)**: Used the ARTEX AI-powered penetration testing framework in a campaign targeting approximately 200 organizations worldwide, compromising at least nine.
- **Unknown actors**: Actively targeting SonicWall SMA1000 appliances and SSL-VPN services; exploiting refrigeration controllers and cold-chain monitoring systems worldwide, potentially causing food spoilage, equipment damage, and fire hazards.
- **North Korean actors**: Stole approximately $6.34 billion from Binance after compromising wallet infrastructure by tricking an employee into installing malware during a fake job interview.
