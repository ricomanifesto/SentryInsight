# Exploitation Report

## Executive Summary

OpenSSH on musl-based Linux distributions is affected by an authentication bypass condition tied to the historical CVE-2016-6210 patch behavior, allowing logins to password-disabled accounts via oversized passwords when specific conditions align. A fix is available in OpenSSH 10.6p2, and Alpine has issued updated packages; however, exploitation status is assessed as potential because no confirmed attacks using the condition have been reported. Systems using glibc or PAM authentication are not affected.

CISA added Apple WebKit/PAC bypass CVE-2024-27834 to its Known Exploited Vulnerabilities catalog following reports of active exploitation, though the supplied assessment classifies this CVE as potential rather than confirmed. Related WebKit activity under CVE-2025-43529 is assessed as unknown, with no definitive attribution to confirmed exploitation in the supplied sources. Apple addressed CVE-2024-27834 in May 2024 updates, and FCEB agencies were directed to apply patches by November 18, 2026.

Zyxel GS1900 switches face an unauthenticated pre-authentication command execution path. CVE-2026-7273 appears in CISA's KEV catalog, but the supplied assessment for both CVE-2026-7273 and the separately tracked CVE-2026-107441 is unknown because evidence does not establish whether the earlier Patch 2 firmware blocked the exploit. Barracuda Email Security Gateway flaws CVE-2026-116606 and CVE-2026-111560 can be chained for pre-authentication root command execution; exploitation is assessed as unknown with no public attack reports tied to the new pair. Apache OFBiz flaws CVE-2026-68524 and CVE-2026-109928, and Docker Sandboxes CVE-2026-103916, are patched but carry unknown exploitation status in the supplied evidence.

## Active Exploitation Details

### CVE-2016-6210 (OpenSSH username enumeration change underlying musl authentication bypass)
- **Description**: A patch introduced in OpenSSH in 2016 to fix a username enumeration vulnerability tracked as CVE-2016-6210 changed how OpenSSH handled accounts without usable password hashes. To prevent username enumeration through response-time differences, OpenSSH was modified to perform password hashing even when an account had no usable password hash, including accounts configured with `*` to block password logins. On musl-based systems, the `crypt()` function also returns `*` when password hashing fails, including when a submitted password exceeds its 256-byte limit, allowing an attacker to submit an oversized password and cause OpenSSH to compare the returned `*` against the account's stored `*`, resulting in a successful login.
- **Impact**: Attackers can log in to certain Alpine Linux and other musl-based Linux accounts configured to block password authentication. On Alpine Linux official AWS and Azure cloud images, the default `alpine` account has passwordless `doas` privileges, which could allow attackers to gain root access. The flaw does not allow bypassing passwords on accounts with valid password hashes.
- **Status**: Fixed in OpenSSH 10.6p2. Alpine Linux administrators are advised to update OpenSSH packages using `apk upgrade openssh`. No attacks using the flaw have been reported.
- **Severity**: unknown
- **Exploitation Status**: potential
- **Action**: patch
- **CVE IDs**: CVE-2016-6210
- **Reporting**: [Bleeping Computer — OpenSSH flaw lets attackers log into password-disabled Linux accounts](https://www.bleepingcomputer.com/news/security/openssh-flaw-lets-attackers-log-into-password-disabled-linux-accounts/), [The Hacker News — OpenSSH Issues Emergency Fix for Flaw Letting Long Passwords Bypass SSH Auth on Alpine Linux](https://thehackernews.com/2026/11/openssh-issues-emergency-fix-for-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: The flaw does not allow attackers to bypass passwords on accounts with valid password hashes; Systems using glibc, including Debian, Ubuntu, and Fedora, and those using PAM authentication are not vulnerable to this attack.
- **Recommended Actions**: The vulnerability has been fixed in OpenSSH 10.6p2, and Alpine Linux administrators are advised to update their OpenSSH packages using apk upgrade openssh.; Admins who can't immediately install the update can mitigate the issue by turning off SSH password authentication with PasswordAuthentication no in their SSH server configuration and restarting SSH.
- **Vendor Links**: https://sshhole.com/; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/; https://www.openssh.org/releasenotes.html; https://seclists.org/fulldisclosure/2016/Jul/51

### CVE-2024-27834 (Apple WebKit/PAC bypass)
- **Description**: CVE-2024-27834 (CVSS score: 5.5) is a case of improper authentication that could allow an attacker with arbitrary read and write capability to bypass Pointer Authentication. It impacts multiple Apple operating systems.

## Attack Vectors and Techniques

- **Oversized password authentication bypass**: Attacker submits a password between 257 and 1,024 bytes to an OpenSSH server on musl; `crypt()` returns `*` on failure, matching the stored `*` of a password-disabled account and granting access.
- **Zero-click WebKit exploit chain**: Malicious JavaScript served via compromised legitimate websites, fake sites, or supply-chain compromise (Plerdy SEO Tracker) triggers browser exploitation and cookie theft.
- **Symbolic link sandbox escape**: A malicious shortcut inside an approved Docker Sandbox workspace tricks `sbx cp` into accessing files outside sandbox boundaries.
- **Pre-authentication Apache OFBiz RCE and account takeover**: Unauthenticated remote code execution and incorrect authentication algorithm enabling full admin account takeover.
- **Chained authorization bypass and command injection**: An unauthenticated attacker restores a crafted configuration backup via CVE-2026-116606, then leverages CVE-2026-111560 command injection to execute code as root on Barracuda Email Security Gateway.
- **Out-of-bounds write via web management interface**: An oversized 140th HTTP parameter overwrites a function pointer on Zyxel GS1900 switches, enabling root command execution without authentication.
- **Trojanized web server backdoor**: A malicious `cwpsrv` binary accepts commands through custom `X-Ngx-Integrity` headers with timestamp and RSA signature validation, suppressing access-log entries.
- **Device-code and adversary-in-the-middle phishing**: Fake AI event invitations use Kali365 for Microsoft device-code phishing and VoidProxy as an AiTM reverse proxy for Google credential and session-cookie theft.
