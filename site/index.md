# Exploitation Report

## Executive Summary

Recent reporting covers a mix of recently patched flaws, zero-day-class issues, and flaws whose exploitation status is unconfirmed, with several scoped assessments rated potential or unknown rather than confirmed active exploitation. CVE IDs are referenced only where explicitly provided in the source material. Networking and infrastructure devices are heavily represented: SonicWall GMS flaws CVE-2026-109593 (CVSS 9.1) and CVE-2026-109594 (CVSS 6.8) affect end-of-life systems with no vendor patch, while CVE-2026-102255 (CVSS 10.0) had fixes shipped and public telemetry describing attack attempts. Zyxel GS1900 switches face CVE-2026-107441 and CVE-2026-7273, where an earlier patch was shown not to stop the exploit and the scoped evidence rates exploitation as unknown.

Operating-system and package-management issues include an OpenSSH/musl authentication bypass (*sshole) tied to the historical CVE-2016-6210 patch behavior, Apple CVE-2024-27834 (CVSS 5.5) added to CISA's Known Exploited Vulnerabilities catalog, Debian/Ubuntu APT CVE-2026-109518 (CVSS 4.0 score 7.7) permitting root code execution via package-download substitution, and Apache OFBiz CVE-2026-68524/CVE-2026-109928 (patched in 24.09.08) allowing pre-authentication remote code execution and account takeover. Docker Sandboxes CVE-2026-103916 is assessed as potential for sandbox escape through symlink abuse.

Threat activity described in the sources includes APT29 (Cozy Bear/Midnight Blizzard) watering-hole operations, suspected Chinese-speaking activity tracked as Kapibala/Red Heron against Zyxel switches, service-desk social engineering by groups such as Scattered Spider, and session-hijacking/device-code phishing campaigns. Where a fix exists, patching is the supported action; where exploitation status is unknown or potential, findings should be treated as requiring investigation and monitoring rather than confirmed compromise.

## Active Exploitation Details

### OpenSSH musl password-disabled account bypass (*sshole) — CVE-2016-6210
- **Description**: A newly disclosed flaw dubbed "*sshole" affects OpenSSH on musl C-library Linux systems (Alpine Linux, OpenWrt, Buildroot, Yocto). Accounts with password hash "*" in /etc/shadow should reject all passwords, but musl's crypt() returns "*" when hashing fails, including for passwords over 256 bytes, so an oversized password matches the stored "*" and authenticates. The behavior traces to the 2016 OpenSSH patch for username enumeration (CVE-2016-6210), which made OpenSSH hash passwords even for unusable hashes. The flaw does not bypass accounts with valid password hashes.
- **Impact**: Attackers can log into password-disabled accounts; on Alpine AWS/Azure images the default "alpine" account has passwordless doas privileges, enabling root access.
- **Status**: Fixed in OpenSSH 10.6p2; Alpine administrators advised to run apk upgrade openssh. No confirmed active exploitation in the scoped evidence (assessed potential).
- **Severity**: unknown

## Attack Vectors and Techniques

- **Oversized password authentication bypass**: Submit a password over 256 bytes so musl crypt() returns "*", matching a stored "*" password hash on OpenSSH/musl systems with password logins ostensibly disabled.
- **Zero-click WebKit exploit chain**: Malicious JavaScript served via compromised legitimate websites, fake look-alike sites, and a supply-chain attack on the Plerdy SEO Tracker to profile visitors and deploy information-stealing payloads.
- **Unauthenticated file read**: Network-accessible attacker reads internal GMS files on SonicWall GMS without authentication.
- **Post-authentication SQL injection**: Authenticated attacker accesses or modifies the GMS database under specific conditions.
- **Pre-authenticated SSRF**: Attacker reaches internal functionality and performs unauthorized operations on SonicWall SMA without authentication.
- **Refrigeration controller manipulation**: Remote manipulation of temperature and defrost settings on compromised cooling controllers to spoil stored goods.
- **Symbolic-link sandbox escape**: Use of a symlink with the "sbx cp" command to access or overwrite files outside an approved Docker Sandbox workspace.
- **Image upload arbitrary file access**: Write arbitrary files and read sensitive files via images uploaded to Rails Active Storage ImageMagick integration (reported separately).
- **Authentication-algorithm account takeover**: Incorrect authentication algorithm implementation in Apache OFBiz enabling full account takeover.
- **APT package-download substitution**: Swap a checked package for a malicious one during APT retry-based downloads, executing attacker code as root.
- **Out-of-bounds HTTP parameter write**: Oversized HTTP parameter overwrites a parameter counter and redirects program flow to attacker-controlled commands on Zyxel GS1900 switches.
- **Device-code phishing**: Abuse of legitimate device-code authentication flows (Microsoft/Adobe/DocuSign lures) to obtain account access or tokens without stealing passwords.

## Threat Actor Activities

- **APT29 (Cozy Bear / Midnight Blizzard)**: Russian state-sponsored group linked with moderate to high confidence to watering-hole operations compromising websites, fingerprinting visitors, and harvesting information from targets of interest; possibly linked to exploitation of previously patched Safari and Chrome vulnerabilities to deliver information-stealing malware.
