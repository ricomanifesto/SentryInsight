# Exploitation Report

## Executive Summary

The most critical activity centers on recently disclosed and patched flaws in internet-facing services: the OpenSSH *sshole/SSHole authentication bypass on musl-based Linux, a Microsoft Paint remote code execution flaw delivered through the Store, the Plex2Shell vulnerability chain affecting QNAP NAS devices, a chained Barracuda Email Security Gateway pre-authentication root exploit, a critical Brotli flaw (CVE-2026-111497), and a Linux kernel MPTCP remote root vulnerability (CVE-2026-98432). Patches are available for most of these issues (OpenSSH 10.6p2, Paint via Microsoft Store, Plex Media Server 1.43.3.10861, Barracuda firmware 9.4.0.030), and administrators should prioritize updating exposed systems.

Under the supplied evidence assessment, exploitation statuses for these findings range from not_observed to potential and unknown; no finding in this report is treated as source-confirmed active exploitation. Patch availability and mitigations such as disabling password authentication or limiting administration interfaces are documented where the sources provide them. Separately, threat activity includes APT29 mobile watering holes, AI-driven phishing and agentic attacks, and attacks on refrigeration and OT systems, which are detailed in the supporting sections below.

## Active Exploitation Details

### OpenSSH username enumeration (CVE-2016-6210)
- **Description**: A username enumeration weakness in OpenSSH introduced by a 2016 patch that changed how OpenSSH handles accounts without usable password hashes, causing password hashing to be performed even for accounts configured with an asterisk (*) to block password logins; this behavior is the root-cause condition behind the *sshole/SSHole authentication bypass on musl-based systems.
- **Impact**: Enables identification of valid usernames and, in combination with musl crypt() behavior on oversized passwords, authentication to accounts that should block password logins.
- **Status**: Historical flaw; remediated by OpenSSH 10.6p2 and distribution patches; patch available.
- **Severity**: unknown
- **Exploitation Status**: potential
- **Action**: patch
- **CVE IDs**: CVE-2016-6210
- **Reporting**: [Bleeping Computer — OpenSSH flaw lets attackers log into password-disabled Linux accounts](https://www.bleepingcomputer.com/news/security/openssh-flaw-lets-attackers-log-into-password-disabled-linux-accounts/), [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html), [The Hacker News — OpenSSH Issues Emergency Fix for Flaw Letting Long Passwords Bypass SSH Auth on Alpine Linux](https://thehackernews.com/2026/11/openssh-issues-emergency-fix-for-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Systems using glibc, including Debian, Ubuntu, and Fedora, and those using PAM authentication are not vulnerable to this attack.; Non-Linux systems, Linux systems built on glibc, and systems that check passwords through PAM are not affected.; OpenWrt handles SSH with Dropbear by default, and Dropbear is not affected.
- **Recommended Actions**: The vulnerability has been fixed in OpenSSH 10.6p2, and Alpine Linux administrators are advised to update their OpenSSH packages using apk upgrade openssh.; Admins who can't immediately install the update can mitigate the issue by turning off SSH password authentication with PasswordAuthentication no in their SSH server configuration and restarting SSH.; Affected users are advised to install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd.
- **Vendor Links**: https://sshhole.com/; https://www.openssh.org/releasenotes.html; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/

### SSHole OpenSSH authentication bypass (CVE-2026-123158)
- **Description**: SSHole (or *sshole), an OpenSSH authentication bypass impacting Linux systems that run OpenSSH on the musl C library with PAM disabled, including Alpine Linux's default OpenSSH server configuration; an unauthenticated attacker supplies an oversized password to access accounts configured without usable passwords without stealing credentials or SSH keys.
- **Impact**: Successful authentication to password-disabled accounts with the account's existing permissions; potential access to deployment credentials, application secrets, connected infrastructure, lateral movement, or service disruption.
- **Status**: Patch available (OpenSSH 10.6p2 / distribution patched packages); exploitation status assessed as unknown per the supplied evidence.
- **Severity**: high
- **Exploitation Status**: unknown
- **Action**: patch
- **CVE IDs**: CVE-2026-123158
- **Reporting**: [The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot](https://thehackernews.com/2026/11/hackers-exploited-openssh-sshole-flaw.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.; Does not allow attackers to bypass passwords on accounts with valid password hashes.
- **Recommended Actions**: Affected users are advised to install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd.; Look in /var/log/messages for sshd lines reading Accepted password for an account that has no password (alpine, root, or any key-only user).; Review doas use and recently created users, files and authorized keys on exposed machines. If you cannot rule out a login, treat the machine as compromised.
- **Vendor Links**: https://previdian.com/CVE-2026-123158; https://nvd.nist.gov/vuln/detail/cve-2026-123158; https://sshhole.com/; https://www.openssh.org/releasenotes.html; https://alpinelinux.org/posts/2026-11-05-openssh-password-authentication-bypass/

- **OpenSSH on musl-based Linux**: OpenSSH servers on Alpine Linux, OpenWrt, Buildroot, and Yocto with PAM disabled and password authentication enabled; affects accounts with * password hash when another account has a valid password hash.
- **Microsoft Paint (Windows)**: builds below 11.2609.401.0; fixed build is 11.2609.401.0 (CVE record lists affected below 11.2605.91.0).
- **Plex Media Server on QNAP NAS**: versions before 1.43.3.10861; QTS, QuTS hero, and other QNAP operating systems are not themselves affected.
- **Barracuda Email Security Gateway**: fixed in version 9.4.0.030 and later; command injection also reaches five other products requiring administrator access.
- **Brotli library**: critical vulnerability CVE-2026-111497.
- **Linux kernel IPv4 TCP / MPTCP**: CVE-2026-98432 allows remote root on MPTCP listeners; Veeam components impacted.
- **Control Web Panel (cwpsrv)**: versions 1.15.10 and 1.24.0 (cwpdoor backdoor; installation requires root access).
- **Refrigeration/cold-chain controllers**: electronic temperature controllers and commercial refrigeration management systems exposed to the internet.
- **Claude Desktop / claude.ai**: Dispatch feature (being retired) exploitable via a malicious browser extension running on claude.ai.

## Attack Vectors and Techniques

- **Oversized password authentication bypass (SSHole)**: Attacker submits a password between 257 and 1,024 bytes; musl crypt() returns * on hashing failure, matching the stored * of a password-disabled account, granting login over SSH.
- **Network out-of-bounds read RCE (Paint)**: Attacker sends a specially crafted packet to an affected service over the network; no sign-in and no user assistance required.
- **Plex2Shell chain**: Four chained Plex Media Server vulnerabilities leading to remote compromise of NAS devices exposed on the public web.
- **Authorization bypass + command injection (Barracuda)**: Unauthenticated restore of a forged configuration backup changes global settings, then a timezone value is executed as a root shell command.
- **Device-code phishing and adversary-in-the-middle (Kali365/VoidProxy)**: Steals Microsoft device-code tokens and Google credentials/session cookies; bypasses multifactor authentication via captured sessions or device-code flow.
- **Browser extension to Claude Desktop RCE (Dispatch)**: A malicious or compromised extension runs scripts on claude.ai and sends instructions to Claude Desktop as if from the user, abusing Approve prompts.
- **Malicious GitHub security projects**: Backdoor and information stealer (AsyncRAT, clipper) delivered via an Electron loader hidden in security-related repositories.
- **Refrigeration controller attacks**: Authentication bypass, arbitrary code injection, or weak configuration used to modify temperature settings and force continuous heating or defrost cycles.

## Threat Actor Activities

- **APT29 (Russian state-sponsored)**: Watering-hole campaigns compromise websites, fingerprint visitors, and harvest information from high-value mobile users.
- **Previdian-observed actors / unknown operator**: SSHole exploitation attempts observed under nine hours after CVE publication; confirmed successful root access on an Alpine Linux honeypot; eight exploitation attempts from IP geolocated to Japan (89.116.89.18) running reconnaissance commands (id, uname, hostname).
- **UNC4841**: Exploited Barracuda flaw CVE-2023-2868 as a zero-day in 2023; unrelated to the 2026 Barracuda pair.
- **Unknown actors**: Multiple QNAP NAS compromise reports via Plex2Shell; CISA added all four Plex flaws to its Known Exploited Vulnerabilities catalog on October 20, 2026.
- **Unknown actor (Brazil)**: cwpdoor backdoor installed on Control Web Panel servers (installation requires root access); Ebury malware also found on one affected server.
- **North Korean actors**: Binance compromise (~$6.34 billion) after an employee was tricked into installing malware during a fake job interview.
- **AI-linked actors / ARTEX**: Agentic attacks scanning public GitHub repositories for secrets, exfiltrating from Azure Key Vault, and targeting Microsoft Entra ID, Azure, and Microsoft 365; activity assessed as ongoing from August 2026.
- **LLMjacking operators**: Resale of stolen cloud LLM access (AWS Bedrock keys) via llm-routing.com and xingjiabiapi.org; IP 23.106.46.239 flagged as an indicator of compromise.
- **Push Security-identified attackers**: Fake OpenAI, SpaceX, and Anthropic event phishing using Kali365 and VoidProxy to steal Microsoft and Google credentials and sessions (detected late October 2026).
