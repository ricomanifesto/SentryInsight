# Exploitation Report

## Executive Summary

Vendors recently issued patches for multiple security flaws, including a Chrome zero-day and four flaws added to CISA's Known Exploited Vulnerabilities catalog. Google addressed CVE-2026-125350, a use-after-free bug in the Chrome XML component, as part of an update addressing nine vulnerabilities; this marks the eighth Chrome zero-day addressed in 2026. CISA added incorrect authorization in IBM Aspera Faspex (CVE-2026-123218), code injection in SignalWire FreeSwitch (CVE-2026-116779), an OpenSSH authentication-bypass flaw tracked as SSHole (CVE-2026-123158), and improper authentication in GPUStack (CVE-2026-102895) to its KEV catalog. Patches are available for each finding; per the supplied evidence assessment, exploitation status for these CVE findings is recorded as unknown rather than confirmed.

Separate campaigns warrant attention. Russia-linked Turla deployed the Cereal toolset against Microsoft Exchange servers at government entities in Kazakhstan and Romania to harvest email. France attributed October sabotage against refrigeration controllers at roughly 700 retail sites to Iranian state-backed unit Shahid Kaveh, citing food losses and fires. The BYOD ransomware gang claimed an attack on Vanderbilt University, and the Ethersphere bee-js/Swarm Desktop supply chain was poisoned via stolen CI credentials. N-able took N-central offline after more than 30 alleged zero-days (Able2Shell) were published with proof-of-concept code, while Qubole customer AWS accounts were abused through assumed roles.

Defenders should prioritize applying the available patches for the listed CVEs and review the referenced advisories. Where the supplied evidence does not confirm exploitation, treat the status as unknown and continue monitoring vendor advisories and telemetry; do not interpret patch availability or exploit research as confirmed active exploitation of any specific CVE.

### CVE-2026-125350 — Google Chrome XML component use-after-free
- **Description**: A high-severity use-after-free bug in the XML component of Google Chrome, assigned CVE-2026-125350. Use-after-free bugs occur when a program attempts to access a memory location after it has been freed. Successful exploitation could allow data corruption, program crashes, or arbitrary code execution. An anonymous security researcher discovered and reported the flaw on November 6, 2026. This is one of several Chrome zero-days addressed in 2026, alongside CVE-2026-2441, CVE-2026-3909, CVE-2026-3910, CVE-2026-5281, CVE-2026-11645, CVE-2026-85046, and CVE-2026-87491.
- **Impact**: Successful exploitation could allow an attacker to achieve data corruption, program crashes, or arbitrary code execution.
- **Status**: Patch available; fixed in Chrome versions 157.0.8103.50/.51 for Windows and macOS, and 157.0.8103.50 for Linux. Exploitation status unknown.
- **Severity**: high
- **Exploitation Status**: unknown

## Attack Vectors and Techniques

- **Supply-chain compromise via stolen CI credentials**: Attackers used Ethersphere's bee-worker release automation to publish malicious bee-js 13.3.0 (npm postinstall script) and Swarm Desktop 0.56.2 (signed build workflow), downloading a loader from api.frameworkmetrics[.]xyz that steals Swarm wallet keys and installs backdoors (evjawbreaker on Linux/macOS, ScreenConnect client on Windows).
- **Use-after-free in Chrome XML component**: Memory corruption when the XML parser frees an object but fails to clear the pointer; later use of the freed memory could allow arbitrary code execution.
- **Incorrect authorization (IBM Aspera Faspex)**: An authenticated user crafts a specific message to bypass authorization and escalate privileges.
- **Code injection (SignalWire FreeSwitch)**: Results in configuration and credential disclosure, arbitrary call control, and command execution.
- **Authentication bypass (OpenSSH / SSHole)**: Unexpected status code or return value allows authentication bypass on OpenSSH for Linux.
- **Improper authentication (GPUStack)**: Allows unauthenticated administrative access, including user and model changes, persistent API-key creation, secret disclosure, and code execution via POST /v2/inference-backends/from-yaml.
- **Refrigeration controller web-interface compromise**: Attackers took remote control of Danfoss and Dixell controllers through web interfaces, started abnormal defrost cycles with no time limit, and disabled temperature-probe safety alerts.
- **iMessage authorization flaws**: Remote attacker could join a group chat and receive messages; a person added to a group could access messages sent before they joined.
- **iOS sandbox escape (worse_query)**: An app sets up an App Group container to reach every app's data container and some system folders on iOS 27 without a jailbreak or kernel exploit.
- **AWS AssumeRole abuse**: Attacker assumed roles in Qubole-connected customer AWS accounts using trusted account 805246085872 and an External ID from outside AWS, then read Secrets Manager, SSM Parameter Store, Lambda environment variables, and S3 data.
- **N-able N-central exploit chains**: Unauthenticated XXE to session theft/password reset/RCE as the nable user; stored XSS executing as root when an administrator views malicious patch metadata; privilege escalation from nable to root; GenericTCP stack overflow achieving root command execution.
- **Turla Cereal Exchange intrusion**: CerealBox injects into Exchange EdgeTransport.exe and hijacks transport-agent handlers to inspect and filter email in memory; CerealNeuron listens on legitimate-looking Exchange paths; no external C2 (the compromised server serves as the control point); commands delivered as encrypted .NET programs executed in memory.

## Threat Actor Activities

- **BYOD ransomware gang**: Claimed responsibility for the Vanderbilt University attack on its data leak site, alleging encrypted databases and stolen student, employee, and research data (over 1 million SSNs, full names, email addresses, phone numbers, records, and domain-controller takeover asserted). BYOD launched in 2026 and previously claimed an attack on the University of New Mexico Health Sciences Center. Vanderbilt had not officially confirmed the group's involvement or encryption at the time of reporting.
- **Turla (aka Snake, Secret Blizzard, Waterbug)**: Russia-aligned, state-sponsored actor linked to Russia's FSB; used the previously undocumented Cereal toolset against governmental entities in Kazakhstan and Romania in late 2025, including harvesting emails involving NATO and European Union addresses at a Romanian government organization. Designed for long-term, stealthy cyberespionage with minimal disk footprint and no external C2 infrastructure.
- **Shahid Kaveh (IRGC cyber-offensive unit)**: Attributed by France to October cyberattacks on refrigeration controllers at roughly 700 French retail sites, causing food losses and at least 15–20 fires. Operates through hacktivist personas including CyberAveng3rs, Soldiers of Solomon, Mr. Soul, and Cyber Isnaad Front; previously claimed attacks on Unitronics (November 2023) and a sabotage campaign against Israeli and U.S. interests (March–April 2026). France attributed only the October French supermarket attacks to this unit, not the later multi-country wave.
- **Sean Bales / Able2Shell researcher**: Disclosed more than 30 alleged zero-day vulnerabilities in N-able N-central with proof-of-concept code (GitHub repository Able2Shell), tested against N-central Appliance 2026.4.0.31; claimed prior unrelated reports were ignored. N-able took hosted N-central offline and stated it had not observed active exploitation; watchTowr reported observing exploitation attempts against N-able N-central honeypots after disclosure.
- **Financially motivated cybercriminal group (Fireworks / LLMJacking)**: Linked to a breach of Fireworks development machines via a third-party cloud provider, aimed at selling tokens from unauthorized access to large language models to illicit routing gateways ("LLMJacking"); cloud AI charges reaching up to $1 million reported for compromised organizations.
- **Qubole AWS attacker**: Unidentified actor broke into multiple Qubole customer AWS accounts between October 14 and October 26, stealing stored secrets and data via assumed roles; not linked to state-backed groups; a separate October 8–11 activity used customers' own AWS access keys and was not linked to the AssumeRole abuse.
- **forcequit (worse_query researcher)**: Published the worse_query iOS sandbox escape proof-of-concept on GitHub; no attacks or thefts involving it were reported by Binance or the researcher. Derivative tools such as WQ Files can read, edit, delete, and clear other apps' data via sideloading.
