Exploitation ReportNovember 13, 2026

Executive Summary

Multiple zero-day and recently patched vulnerabilities are under active or suspected exploitation across security gateways, remote management platforms, container registries, and operating systems. Check Point Software confirmed active exploitation of CVE-2026-123039, a local privilege escalation flaw in the Gaia OS DynamicCLI interface, against a couple of dozen customers since late October. Attackers chained this flaw with PHP2Shell vulnerabilities (CVE-2026-109618 and CVE-2026-109619) to breach Check Point Security Gateways, deploy webshells and the TSGA backdoor, pivot to VMware ESXi hosts, and execute destructive wiper malware.

N-able N-central faces confirmed exploitation of CVE-2026-90436 through the 4EverAble2Shell exploit chain, with threat actors deploying cryptocurrency miners on at least 21 servers, including systems running the latest Hotfix 2. Other recently patched critical flaws—including Red Hat Quay CVE-2026-123710 (CVSS 9.8) and CVE-2026-110697 (CVSS 9.9), Apache HTTP Server CVE-2026-119618, PostgreSQL CVE-2026-6460 (CVSS 8.8), and multiple Check Point and Microsoft vulnerabilities—have unknown exploitation status in the supplied sources, meaning confirmed active exploitation is not established despite patch urgency or proof-of-concept disclosure.

Defenders should prioritize patching CVE-2026-123039, CVE-2026-90436, and the PHP2Shell flaws where mitigations are available, while monitoring for indicators of compromise associated with the Check Point attack chain and N-central cryptojacking activity. Several other vulnerabilities remain without confirmed exploitation evidence, and their status should be treated as unknown pending further telemetry.

Earlier reporting
  • CVE-2026-123039. First report of this CVE in the retained archive.
  • Description: A local privilege escalation vulnerability in the DynamicCLI IPC interface used to send privileged command requests to the root-level Gaia OS DynamicCLI (dynamic_server) daemon. The daemon runs as root and listens on a world-writable local socket (/tmp/dynamic_socket) without authenticating connecting processes. An authenticated local user can send a command to the socket and have it executed as root.
  • Impact: Attackers can gain root privileges and establish persistence on vulnerable Check Point devices. In observed attacks, threat actors used it to deploy webshells, the TSGA backdoor, and pivot to VMware ESXi hosts for destructive wiper deployment.
  • Status: Exploitation status is unknown. Check Point released emergency hotfixes. A temporary mitigation is to stop the dynamic_server process and prevent it from restarting.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: Check Point advised security teams who can't immediately deploy the CVE-2026-123039 hotfixes to stop the dynamic_server process and prevent it from restarting as a temporary mitigation measure.

Reporting
  • The Hacker News — Critical Red Hat Quay Flaw Lets Attackers Read and Overwrite All Private Container Images in a Registry · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: access.redhat.com, access.redhat.com (2)

Earlier reporting
  • CVE-2026-123710. First report of this CVE in the retained archive.
  • Description: A critical flaw in Red Hat Quay that allows an attacker who can access a Quay registry to read and overwrite private container images in every repository. Quay uses keys it trusts to sign access tokens. The flaw lets an attacker add their own key to the keys Quay trusts, with no expiry date, so Quay accepts tokens signed with that key for any repository.
  • Impact: An attacker can retrieve private images and any secrets or credentials stored within them. The attacker can also push or overwrite images, and the change propagates to every system that later pulls those images. The planted key survives restarts until removed and can delete keys that running Quay instances use.
  • Status: Exploitation status is unknown. Red Hat has released fixed builds for eight Quay 3 branches. Turning off anonymous access does not protect against this flaw.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: At the proxy or load balancer, block the /keys endpoint for everything except trusted internal components.; Search the audit logs for service_key_rotate and service_key_delete events where expiration_date is null.; Remove any approved service keys you do not recognize.; Install the fixed release. Until it is running, an attacker can add a new key the same way, so deleting one does not last.

Attack Vectors and Techniques

  • Local privilege escalation via unauthenticated socket: The Gaia OS DynamicCLI daemon listens on a world-writable local socket (/tmp/dynamic_socket) without authenticating connecting processes, allowing an authenticated local user to send commands executed as root (CVE-2026-123039)
  • PHP unauthenticated remote code execution: PHP2Shell flaws (CVE-2026-109618 and CVE-2026-109619) allow unauthenticated RCE via the Mobile Access portal on Check Point Security Gateways
  • Apache Axis unsafe class instantiation: Crafted SOAP requests cause attacker-selected JLine classes to process malicious input, executing commands as the nable service account, then escalating to root via N-central privilege escalation (CVE-2026-90436)
  • Client-side file-transfer abuse: SCKit's RelayTrap component attempts to send a malicious file from an infected customer endpoint back to an MSP technician's workstation during a ScreenConnect session (CVE-2026-84869)
  • PostgreSQL type confusion: Composite type fields are changed while older values persist, allowing the server to read old values as new types, leading to authenticated remote code execution (CVE-2026-6460)
  • HTTP/2 race condition: Concurrent execution using shared resources with improper synchronization in mod_http2 assign_headers() corrupts heap memory for remote code execution (CVE-2026-119618)
  • SEV-SNP Reverse Map Table manipulation: During VM startup, PSP writes to the RMP are redirected, leaving protections uninitialized, enabling hypervisor read/write of confidential VM memory and forged attestation reports (CVE-2026-0462)
  • Transient scheduler saved-state leakage: Hypervisor-induced VM start failure caches saved state without cleanup, allowing register and disk-encryption key recovery via TSA (CVE-2026-40671)
