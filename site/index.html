Executive Summary

Critical Java and infrastructure vulnerabilities dominate this reporting period, including the Java4Shell flaw (CVE-2026-114938) in the OpenJDK Base64 decoder, which allows unauthenticated remote code execution on applications such as Keycloak, Jira, and Jenkins. CISA has urged immediate patching, though no exploitation in the wild has been observed. Separately, F5 disclosed CVE-2026-94127, a BIG-IP APM flaw that was later exploited and added to CISA's Known Exploited Vulnerabilities catalog. NGINX also faces a decade-old HTTP/2 integer underflow (CVE-2026-123007) with public proof-of-concept code, though no attacks have been reported.

Threat actor activity remains significant. Russia-linked Cold Relic weaponized a cloud compromise to breach a second U.S. organization through stolen Google Workspace data, rogue MFA devices, and identity impersonation. Suspected Chinese APT activity continues with the EggStreme operators retooling malware against Philippine government targets, while Mustang Panda used ASEAN Summit lures to deliver PlugX. Earth Alux expanded its arsenal with PerfectPioneer and KUKURAT RATs, exploiting unpatched Microsoft Exchange servers and using HTTP/3 for command-and-control communications.

Additional notable events include the sentencing of a Scattered Spider member for SIM-swapping crypto theft, an Optimizely third-party JavaScript supply chain attack affecting 178 organizations, and an AMD firmware flaw (CVE-2026-43613) allowing physical-access TPM lockout resets to crack Windows Hello and BitLocker PINs. Exploitation status for many of these vulnerabilities remains unknown or not observed based on the supplied evidence.

Vendor guidance: oracle.com, openjdk.org, cisa.gov, calif.io

Earlier reporting
  • CVE-2026-114938. First report of this CVE in the retained archive.
  • Description: A memory-corruption flaw in Java's hardware-accelerated Base64 decoder on x86-64 processors with AVX-512 VBMI permits unauthenticated remote code execution or JVM crashes when malformed Base64 input is processed before authentication.
  • Impact: Attackers without accounts can achieve remote code execution on Keycloak, Atlassian Jira, Atlassian Confluence, JFrog Artifactory, Jenkins, and PingFederate under default settings, with authenticated exploitation possible on Apache Kafka Broker, Apache Solr, Elasticsearch, Gerrit, and Spinnaker.
  • Status: Exploitation has not been observed in the wild; patches are available from Oracle, OpenJDK, Amazon Corretto, and Azul Zulu, while Red Hat fixes remain pending.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: Identify affected Java installations and review software inventory for JDKs and Java runtimes, including those bundled with third-party applications or included in container images and appliances; apply relevant Java and vendor patches as soon as they are available; if immediate patching is not feasible, implement temporary compensating controls, such as restricting and validating Base64 input at the application boundary, enforcing input-size limits, and limiting unauthenticated access; start the JVM with -XX:-UseBASE64Intrinsics to turn off only the faster Base64 code, or use -XX:UseAVX=2 on x86-64 servers to turn off AVX-512 entirely as temporary workarounds.

Reporting

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: nginx.org, my.f5.com

Earlier reporting
  • CVE-2026-123007. First report of this CVE in the retained archive.
  • Description: A decade-old integer underflow in NGINX HTTP/2 support permits unauthenticated remote code execution when HTTP/2 is enabled and ASLR is turned off or can be bypassed.
  • Impact: Attackers can run code with NGINX worker process permissions; privilege escalation to root may require a separate Linux kernel SCTP bug, even inside Docker containers.
  • Status: No attacks have been reported by the vendor, Wiz, or Rapid7; CISA's Known Exploited Vulnerabilities catalog did not list the flaw as of publication; proof-of-concept code is publicly available on GitHub. Exploitation status is unknown.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: NGINX Plus R34 to R36: no fix listed.
  • Recommended Actions: Upgrade to NGINX Open Source 1.31.9 or 1.30.7, or NGINX Plus 37.3.0.1 and 37.0.8.1; after upgrading, restart NGINX fully or use its live binary upgrade because a reload alone leaves the old executable running; turn off HTTP/2 as a temporary mitigation by setting http2 off in affected server blocks or removing http2 from listen directives; block the SCTP kernel module from loading until the Linux kernel bug is fixed.

MediumExploitation unknownMitigateCVE-2026-43613#

Reporting
  • The Hacker News — New Attack Bypasses TPM Lockout to Crack Windows Hello and BitLocker PINs in Days, Not Years · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: amd.com, intel.com

Earlier reporting
  • CVE-2026-43613. First report of this CVE in the retained archive.
  • Description: An AMD processor firmware flaw allows the TPM lockout count for Windows Hello and BitLocker PINs to be reset by copying saved state back to the flash chip, enabling short PINs to be cracked through brute-force guessing.
  • Impact: A four-digit Windows Hello PIN can be found in a worst-case of 40 hours compared to 69 days with lockout functioning; a default six-digit BitLocker PIN can be found in about 20 days compared to 19 years with lockout functioning.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Intel components were not demonstrated to be vulnerable; ARM64 chips do not run the affected code path.
  • Recommended Actions: Add at least two digits to Windows Hello and BitLocker PINs; for Windows Hello for Business, raise the Minimum PIN length policy; for BitLocker, raise the Configure minimum PIN length for startup policy and consider enabling enhanced PINs; install AMD firmware updates when available between November 2026 and February 2027; keep PCs under physical control and watch for signs of tampering until fixes are installed.

Affected Systems and Products

  • NGINX Open Source and NGINX Plus: Affected by HTTP/2 integer underflow and related flaws in versions from 1.9.5 through 1.31.8; NGINX Plus 37.x releases before fixed builds and R34 to R36 also affected.
  • Oracle Java SE, OpenJDK, Amazon Corretto, Azul Zulu, Red Hat OpenJDK, GraalVM: Affected by Java4Shell in Java 17.0.6 and later, Java 21, 25, and 27 on x86-64 processors with AVX-512 VBMI; Java SE 8 Performance Pack build 8u511b33-perf also affected.
  • F5 BIG-IP: Affected by six critical TMM stack-buffer overflow flaws and six lower-rated flaws in iRules, APM, iControl SOAP, iControl REST, and SAML configurations; some affect BIG-IP Next for Kubernetes and BIG-IP CNF.
  • Puppet Enterprise and Puppet Core: Affected by deserialization RCE in Puppet Enterprise 2026.0.0 before 2026.0.1, 2025.0.0 before 2025.12.1, 2023.8.0 before 2023.8.13, Puppet Core 9.0.0 before 9.1.3, and Puppet Core 8.x before 8.22.2; OpenVox implementations also affected.
  • Apache Airflow: Affected by unauthenticated RCE vulnerability.
  • AMD Ryzen, Ryzen AI, Ryzen Threadripper, Athlon, and EPYC processors: Affected by firmware TPM flaw allowing lockout reset on systems with firmware TPM and RPMC flash or certain Winbond flash chips.
  • Microsoft Exchange Servers: Exploited by Earth Alux for initial access in Southeast Asian government targeting.

Attack Vectors and Techniques

  • HTTP/2 Exploitation: Malformed HTTP/2 requests sent to NGINX servers with HTTP/2 enabled trigger an integer underflow, enabling remote code execution without authentication.
  • Base64 Decoder Memory Corruption: Malformed Base64 strings ending with extra padding characters cause out-of-bounds writes in Java's AVX-512 accelerated decoder, reachable through HTTP Basic login headers, SAML artifacts, and CSRF tokens before authentication.
  • Deserialization of Untrusted Data: A crafted rich-data type submitted through a PUT request to Puppet's report-processing code allows arbitrary code execution as the service user.
  • Certificate-Name Authorization Bypass: Allows unauthorized access in Puppet and OpenVox by bypassing certificate name checks.
  • TPM Lockout Reset via Physical Access: Copying saved TPM state back to the flash chip resets incorrect PIN guess counters, enabling brute-force attacks on Windows Hello and BitLocker PINs.
  • DLL Sideloading: Malicious DLLs are loaded under legitimate system library names to execute payloads, used by EggStreme and Mustang Panda malware.
  • MFA Push Notification Fatigue: Repeated MFA prompts sent until a victim accepts, allowing attacker registration of rogue devices and passkeys (Cold Relic).
  • HTTP/3 C2 Communication: Malware uses HTTP/3 over QUIC for command-and-control communications to evade detection (Earth Alux).
  • Third-Party JavaScript Supply Chain: Compromised Optimizely platform served malicious JavaScript to visitors of 178 websites without requiring user interaction.
  • PyPI Package Compromise via .pth Files: Malicious Python package versions drop .pth files in site-packages that execute credential stealers on every Python interpreter start.

Threat Actor Activities

  • EggStreme Operators (suspected Chinese APT): Rebuilt toolkit targeting government organizations in the Philippines; uses DLL sideloading, a passive variant that never beacons out, campaign-specific certificate authorities, and VBScript payloads launched over SMB from unmanaged systems; initial access vector remains unknown.
  • Mustang Panda: China-aligned group targeting Philippine government officials as of late October 2026 using ASEAN Summit lures, including a Laos-Philippines bilateral meeting agenda decoy, to deliver PlugX remote-access malware via DLL sideloading.
  • Earth Alux (Ink Dragon, Jewelbug, REF7707, UAT-11587, TGR-STA-0049): China-nexus actor targeting Southeast Asian government entities since at least July 2025; gains initial access through exploitation of vulnerable unpatched Microsoft Exchange servers to deploy ASPXSpy and Godzilla web shells, or through phishing emails with decoy PDFs; deploys PerfectPioneer RAT and KUKURAT modular implant using HTTP/3 for C2 communications.
  • Cold Relic (COLDRIVER, UNC4057, Callisto, Gossamer Bear, Star Blizzard): Russia-linked cyber espionage group that weaponized a single Google Workspace compromise to breach a second U.S. organization; uses stolen Super Admin credentials, MFA push fatigue, rogue MFA devices, passkeys, Google Takeout for data exfiltration, and impersonation emails to conduct social engineering against professional contacts.
  • Scattered Spider (0ktapus, Octo Tempest, UNC3944, Muddled Libra): A member was sentenced to six years in prison for SMS phishing, SIM swapping, and crypto theft exceeding $11.6 million; group uses social engineering, MFA bombing, phishing, and SIM swapping to breach telecommunications, technology, and cloud providers.
