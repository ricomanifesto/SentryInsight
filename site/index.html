Exploitation ReportNovember 27, 2026

Executive Summary

Security researchers have reported multiple recently patched and unpatched vulnerabilities under active exploitation or assessed as potential exploitation targets. GeoServer flaws including CVE-2026-120705 and CVE-2026-129244 were observed in honeypot networks, with researchers describing unauthenticated remote code execution chains combining several flaws. Drupal's CVE-2026-132165 (Fail2Install) was added to CISA's Known Exploited Vulnerabilities catalog following reports of exploitation on live sites. Exploitation status is unknown for these findings per the supplied evidence contract.

Critical infrastructure and enterprise products are also affected. Danfoss AK-SM 8xxA Series refrigeration controllers contain CVE-2026-129713, an unpatched stack-based buffer overflow that allows unauthenticated remote code execution with webserver privileges; attacks against supermarket refrigeration systems in Europe have been attributed to Iranian threat actors. Palo Alto Networks devices are targeted through chained PHP2Shell (CVE-2026-109618, CVE-2026-109619) and Fragnesia (CVE-2026-46300) exploits to deploy webshells and execute commands as root. Mitel MiCollab flaws including CVE-2026-133323 (CVSS 10.0) and CVE-2026-133303 (CVSS 9.0) were weaponized in an AI-assisted data theft campaign, with web shell deployment observed before patches were released.

Supply chain and social engineering campaigns remain active. North Korean-linked PolinRider poisoned over 7,600 GitHub repositories using Ethereum blockchain dead drops to conceal C2 infrastructure. Multiple malicious NuGet packages targeted .NET developers through fake job assessments. AI-driven autonomous cyberattacks were observed against critical infrastructure in Italy and Switzerland, with attackers using frameworks such as ARTEX AI, DeepSeek Harness, and PentAGI to chain vulnerabilities and maintain persistence. Exploitation status is unknown for these campaign-related findings unless explicitly stated otherwise in the source evidence.

Attack Vectors and Techniques

  • Ethereum Blockchain Dead Drop (NullReceiver): Malware reads Ethereum wallet transactions to decode C2 server addresses from wallet input data, using JavaScript executed via Node.js processes
  • WFS Stored Query Manipulation: Attackers create and invoke stored queries on GeoServer to validate vulnerability, then delete them immediately to avoid detection
  • Remember-Me Cookie Forgery: Predictable signing key ("geoserver") combined with password hashes from disclosed "users.xml" allows forgery of administrator authentication cookies
  • JDBC Deserialization: Administrator-controlled JDBC configuration points to uploaded HSQLDB database where bundled driver deserializes stored values to execute commands
  • Service Name Prefix Bypass: Prefixing WFS name as "x/WFS" slips past admin-only rules for stored queries
  • Unauthenticated CGI Buffer Overflow: Specially crafted HTTP/S POST requests trigger stack-based buffer overflow in Danfoss controller CGI handler
  • XML Injection: Arbitrary file read and command injection via unauthenticated WFS GetFeatureById XML injection on GeoServer
  • PHP2Shell Chaining: Unauthenticated PHP remote code execution chained with Linux kernel local privilege escalation (Fragnesia) to deploy webshells and execute as root
  • Software Supply Chain Poisoning: Malicious packages published to npm, PyPI, NuGet, and GitHub repositories via hijacked maintainer accounts and fake job assessments
  • AI-Driven Autonomous Exploitation: Autonomous AI agents chain vulnerabilities, misconfigurations, and compromised credentials to compromise exposed endpoints within hours
