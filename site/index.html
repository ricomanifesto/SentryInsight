Executive Summary

Recent patching activity highlights a critical remote code execution flaw in Microsoft Paint (CVE-2026-83844) that is now fixable only through the Microsoft Store rather than Windows Update. The vulnerability carries a CVSS score of 8.1 and has not been observed in exploitation, but its non-standard delivery path creates uneven patch coverage across endpoints. Microsoft rates the flaw as Important and notes that successful exploitation requires a deep understanding of the target system.

Multiple recently disclosed flaws in OpenSSH, Plex Media Server, SonicWall firewalls, Barracuda Email Security Gateway, Brotli, and the Linux kernel are under assessment with exploitation status marked unknown in the supplied evidence. Vendors have released patches or urgent guidance for several of these issues, including OpenSSH 10.6p2, Plex Media Server 1.43.3.10861, SonicOS updates, and Barracuda firmware. Defenders should prioritize patching internet-facing services even where confirmed exploitation has not yet been established.

AI-driven threats continue to expand, with autonomous agents implicated in breaches, credential theft, and large-scale phishing campaigns. Organizations should monitor for anomalous AI agent behavior, reinforce authentication controls on exposed infrastructure, and treat AI-assisted offensive frameworks as an emerging risk vector across cloud and on-premise environments.

Vendor guidance: msrc.microsoft.com, nvd.nist.gov

  • Description: Remote code execution flaw in Windows Paint involving an out-of-bounds read that could let an attacker run code over a network by sending a specially crafted packet to an affected service.   • Exceptions: None stated in supplied sources.
  • Recommended Actions: Update Paint through the Store, or let the Store auto-update install the fixed build. In Intune and other device-management tools, the Store app update scan does this across many PCs. Run both commands again and check that every copy shows 11.2609.401.0 or later.; The advisory lists no workaround or mitigation. Before the fix reached the Store, Vitko suggested removing Paint where nobody needs it, for every user and from the provisioned copy. He did not test that step.

Reporting
  • The Hacker News — Hackers Target OpenSSH SSHole Flaw Within Hours of Disclosure, Gain Root on Honeypot · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: openssh.org, nvd.nist.gov, alpinelinux.org

  • Description: Authentication bypass flaw impacting Linux systems running OpenSSH on the musl C library with Pluggable Authentication Modules (PAM) disabled, including Alpine Linux's default OpenSSH server configuration. An unauthenticated attacker can supply an oversized password between 257 and 1,024 bytes to access accounts deliberately configured without usable passwords, without stealing credentials or SSH keys.
  • Impact: A successful SSHole attack grants access with the compromised account's existing permissions, potentially enabling access to deployment credentials, application secrets, connected infrastructure, lateral movement, or service disruption.
  • Status: Addressed in OpenSSH 10.6p2. Exploitation status is unknown per the supplied assessment; the underlying issue dates to a 2016 patch for CVE-2016-6210.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Does not affect Dropbear, glibc-based Linux distributions, non-Linux systems, and systems that check passwords through PAM.
  • Recommended Actions: Install OpenSSH 10.6p2 or their distribution's patched package, and then restart sshd.; Alpine is also recommending that users investigate "Accepted password for" log entries involving accounts that should not accept password logins. Look in /var/log/messages for sshd lines reading Accepted password for an account that has no password (alpine, root, or any key-only user). Review doas use and recently created users, files and authorized keys on exposed machines. If you cannot rule out a login, treat the machine as compromised.

Affected Systems and Products

  • Microsoft Windows Paint: Builds below 11.2605.91.0 affected per CVE record; fixed build 11.2609.401.0 delivered via Microsoft Store only.
  • OpenSSH on musl with PAM disabled: Linux systems including Alpine Linux default OpenSSH server configuration; not affecting glibc-based distributions or PAM-enabled systems.
  • Plex Media Server: QNAP NAS devices running Plex Media Server; fixed in version 1.43.3.10861 via QNAP App Center.
  • SonicOS Gen7 and Gen8: Versions 7.3.3-7015 and earlier (Gen7) and 8.2.2-8015 and earlier (Gen8); fixed in 7.3.4-7013 and 8.2.3-8015.
  • SonicWall SMA1000: Secure remote access appliances targeted in October 2026 exploitation attempts.
  • Barracuda Email Security Gateway: Fixed in version 9.4.0.030 and later; authorization bypass affects only this product.
  • Veeam Software Appliance: Linux-based Veeam Backup & Replication appliances; affected components receiving patched kernel via private fix or Veeam Updater.
  • Brotli library: Critical vulnerability discovered by AI model; specific versions not stated in supplied sources.
  • Linux kernel: IPv4 TCP networking code with MPTCP listeners vulnerable to remote root execution.

Attack Vectors and Techniques

  • Specially crafted network packet: Microsoft Paint RCE flaw can be triggered by sending a specially crafted packet to an affected service over the network with no sign-in or user assistance required.
  • Oversized password authentication bypass: SSHole flaw allows authentication to password-disabled OpenSSH accounts by submitting passwords between 257 and 1,024 bytes, causing hash failure and asterisk comparison bypass.
  • Chained authorization bypass and command injection: Barracuda Email Security Gateway chain uses a crafted configuration backup restore to gain administrative access, then leverages command injection for root-level command execution with no login.
  • SAML authentication bypass: SonicWall SSL-VPN flaw allows attackers with valid alternate authentication credentials to bypass SAML controls, potentially bypassing enforced MFA.
  • Remote unauthenticated MPTCP exploitation: Linux kernel flaw enables remote attackers to execute commands as root on servers with Multipath TCP listeners without authentication.
  • AI agent autonomous attack chain: ARTEX and similar frameworks automate reconnaissance, exploitation, credential scanning, and data exfiltration with minimal hands-on-keyboard interaction.

Threat Actor Activities

  • Previdian: Observed first SSHole exploitation attempt less than nine hours after CVE publication; confirmed successful root access on an Alpine Linux honeypot. Recorded eight exploitation attempts from IP 89.116.89[.]18 geolocated to Japan, using oversized passwords and reconnaissance commands including id, uname, and hostname.
  • UNC4841: Exploited Barracuda Email Security Gateway via CVE-2023-2868 as a zero-day in 2023 attacks; unrelated to the 2026 Barracuda flaws.
  • Vapor Panda: Chinese cyber-espionage group reported by CrowdStrike to have used the ARTEX AI-powered penetration testing framework in a campaign targeting approximately 200 organizations, compromising at least nine.
  • Unknown actors: Chainalysis breach involved offensive agentic techniques exposing credentials and live tokens for all customers; actor unknown but activity assessed similar to other recent tech platform incidents.
  • Unknown threat actors: QNAP NAS compromises via Plex2Shell vulnerability chain with multiple reported suspected customer compromises; CISA urged federal agencies to patch within three days.
  • Unknown actors: SSL-VPN MFA bypass exploitation reported against SonicWall, confirmed by CISA KEV catalog entry for CVE-2026-19868.
