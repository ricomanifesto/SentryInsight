Exploitation ReportNovember 21, 2026

Executive Summary

Chinese-linked threat actor Armory Castle (formerly UNC5221) exploited VMware vCenter zero-day CVE-2026-123890 in early September 2026, achieving remote authentication bypass and administrative access to virtualized environments. Broadcom released emergency patches on November 19, 2026, but the exploitation status remains unknown under the supplied evidence contract despite public reporting of in-the-wild attacks. A separate actively exploited F5 BIG-IP APM zero-day, CVE-2026-94127, was patched in September 2026 after being used in remote code execution attacks.

Cisco Expressway flaw CVE-2026-76466 carries a potential exploitation status following public release of a proof-of-concept and observed in-the-wild activity against a Russian organization, while WhatsApp vulnerability CVE-2026-44908 was patched with exploitation status unknown. Additional critical flaws in BeyondTrust Remote Support (CVE-2026-102764) and Ivanti Connect Secure (CVE-2025-22457) are referenced in threat actor campaign reporting without confirmed exploitation status under this contract.

Android malware frameworks Bazuka and ArcticRAT demonstrate LLM integration for credential theft and device control, though no CVE IDs are assigned to these threats. An unpatched Windows FastUnlock technique permits lock-screen program execution with physical access but has not been observed in real attacks. Threat actor activity includes state-sponsored espionage by Armory Castle, North Korean ransomware deployment by Kimsuky, and Pakistani surveillance campaigns via GravityRAT.

  • Recommended Actions: Keep machines that can go missing out of the wrong hands; add a startup PIN to BitLocker on sensitive machines; shut down or hibernate devices when they leave someone's control; watch for an official fix and apply it when available.

Affected Systems and Products

  • VMware vCenter Server: Versions prior to fixed releases in VMSA-2026-0009, including vCenter 8.0 and 7.0, VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform, and VMware Telco Cloud Infrastructure
  • BeyondTrust Remote Support: Appliances compromised before lateral movement into internal Linux systems and VMware infrastructure
  • F5 BIG-IP APM: BIG-IP Access Policy Manager and BIG-IP iRules configurations exposed online, with over 177,000 BIG-IP instances tracked by Shadowserver
  • Cisco Expressway Series: Release X14 and earlier, and Release X15.5.3 and earlier devices
  • WhatsApp for Android and iOS: Multiple client versions prior to patched releases
  • Windows Computers: Machines with physical access risk, Microsoft account accessible through lock screen recovery, and BitLocker configured for automatic TPM unlock
  • Android Devices: Devices targeted by Bazuka and ArcticRAT malware frameworks via malicious dropper apps and Google Play Store impersonation

Attack Vectors and Techniques

  • Remote Authentication Bypass: Unauthenticated attacker with network access bypasses vCenter Server authentication via the VMware Directory Service DCE/RPC interface using SRP-6a session key disclosure
  • Proof-of-Concept Exploitation: Publicly available PoC exploit for Cisco Expressway used to gain root command execution on internet-facing devices
  • Zero-Day Remote Code Execution: F5 BIG-IP APM vulnerability exploited in attacks before patch availability, enabling arbitrary code execution on vulnerable configurations
  • Physical Access Lock Screen Bypass: Use of Windows Narrator screen reader and lock screen recovery options to start programs without authentication on locked workstations
  • ClickFix Malware Delivery: Social engineering lures directing users to execute malicious commands via PowerShell, msiexec.exe, DLL sideloading, and MSI installers masquerading as legitimate tools
  • AI-Powered Malware Frameworks: Android trojans using accessibility services, ADB bridge, WebSocket C2 channels, and LLM control panels for credential theft, overlay attacks, and remote device control

Threat Actor Activities

  • Armory Castle (formerly UNC5221): Suspected Chinese state-sponsored cyberespionage group exploiting VMware vCenter zero-day CVE-2026-123890 and BeyondTrust Remote Support zero-day CVE-2026-102764 in a single campaign since September 2026; deployed BONESAW, SAWSNAKE, SLIMSAVAGE, CAGEMATCH, BEARBONES, and LAZYBONES to maintain persistence, escalate privileges, and exfiltrate data from virtualized environments
  • Kimsuky: North Korean hacking group distributing Funhouse ransomware via malicious Hangul documents disguised as resumes, with attack chains similar to previous endpoint ransomware distribution cases
  • SpaceCobra and Cosmic Leopard: Pakistani threat actors conducting GravityRAT surveillance campaigns targeting defense job seekers in India through fake recruitment portals and malicious Android apps
  • Unattributed actors: Cisco Expressway exploitation against a Russian organization using custom Python scripts possibly developed with AI assistance; ROMULUS ClickFix campaigns distributing CNCMachineRMS and Legion Loader via signed binary sideloading
  • Chinese-nexus threat actor: Used autonomous AI agent platform Cairn to discover and exploit a zero-day in MONAI Label medical imaging application between September 8 and 10, 2026, targeting East Asian educational institutions outside China
