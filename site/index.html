Exploitation ReportNovember 27, 2026

Executive Summary

Recent exploitation activity centers on recently disclosed flaws in internet-facing and operational-technology infrastructure, alongside state-motivated and financially motivated intrusion campaigns. The Linux kernel NFS server flaw CVE-2026-99362 (NFS2ROOT) is a 12-year-old heap buffer overflow allowing remote root compromise on exposed servers; exploitation has not been observed in the wild, and a patch is available. CISA's KEV catalog additions include multiple Mitel MiCollab flaws, Vates Xen Orchestra CVE-2026-133469, and HPE Juniper Session Smart CVE-2026-103406, with assessed exploitation statuses that remain unconfirmed in the supplied reporting.

State-linked actors are also active. A suspected Vietnam-linked operation (WeaveLotus/RedOps) intruded into Thai and Philippine government and military systems, reportedly exploiting GeoServer CVE-2024-36401 and osTicket CVE-2021-42235. North Korea-linked PolinRider compromised thousands of GitHub repositories to distribute a Python loader and infostealer, while an Iranian group (Volant Manticore) targeted Cypriot organizations. Separately, AI-powered frameworks such as ARTEX were used in automated attacks against government and critical-infrastructure targets.

Defenders should prioritize patching CVE-2026-99362 and KEV-listed flaws where fixes exist, restrict exposed management and operational interfaces, and monitor for supply-chain and credential-theft activity. No finding in this report is assessed as confirmed active exploitation except as explicitly noted; several statuses are unknown or potential.

Earlier reporting
  • CVE-2026-99362. First report of this CVE in the retained archive.
  • Description: CVE-2026-99362 is a 12-year-old heap buffer overflow in the Linux kernel NFS server (nfsd) that lets remote, unauthenticated attackers write beyond an allocated memory buffer and gain root privileges.
  • Impact: Attackers can corrupt kernel memory, bypass KASLR, and execute commands with root access on exposed Linux servers through low-complexity attacks with no user interaction.
  • Status: Exploitation has not been observed in the wild; a patch is available and should be applied immediately, followed by a reboot.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Hosts without nfsd (v4.1 or 4.2) loaded and running, or without TCP port 2049 reachable over the Internet
  • Recommended Actions: Apply the latest kernel security updates from the Linux distribution vendor immediately, then reboot the system to ensure the patched kernel is in use.; Those who can't apply a patch immediately should restrict access to the NFS server over TCP port 2049 to trusted clients or networks.; Additionally, if NFS sharing is not required on the system, admins can stop and disable the nfs-server service in /etc/nfs.conf.

Affected Systems and Products

  • Linux kernel NFS server (nfsd): Kernels older than 6.12.117, 6.18.61, 7.3.2, or 7.4-rc1 with nfsd (v4.1 or 4.2) loaded and running and TCP port 2049 reachable over the Internet
  • Platform: Linux servers, NAS appliances, build farms, and Kubernetes storage nodes exposing port 2049
  • Mitel MiCollab: Versions 10.3 and earlier, Audio/Web/Video Conferencing (AWV) component
  • Platform: On-premises conferencing and collaboration systems
  • Vates Xen Orchestra: Authentication-bypass flaw via crafted token with empty JSON object
  • Platform: Virtualization management appliances
  • HPE Juniper Session Smart Conductor and Session Smart Router: Command injection via specially crafted salt minion ID
  • Platform: Networking and session smart routing appliances
  • Danfoss AK-SM 8xxA Series: Versions 5.4.0 and earlier (CVE-2026-129713); AK-SM 800A Series (CVE-2025-41450)
  • Platform: Refrigeration controllers used in supermarket and cold-chain environments
  • GeoServer and osTicket: Exploited web applications in WeaveLotus/RedOps intrusions
  • Platform: Geospatial services and ticketing systems in government and military networks

Attack Vectors and Techniques

  • NFS2ROOT heap buffer overflow: Maliciously crafted NFS requests cause the NFS server to write beyond an allocated kernel memory buffer, bypass KASLR, and place a callback that executes a command with root privileges when the connection closes
  • Vector: TCP port 2049 reachable nfsd on Linux servers
  • Second-order SQL injection (Cacti 4HTTP2SHELL/4HTTP2ROOT): An unauthenticated guest writes non-numeric text into "preview_graphs_per_page," which is stored and later executed as SQL when the graph preview page loads, ultimately passing a poller-table value to PHP popen() for remote code execution
  • Vector: Unauthenticated HTTP guest surface (four requests)
  • NullReceiver / EtherHiding: C2 IP addresses are encoded in Ethereum wallet transaction calldata; malware decodes wallet input as JavaScript and fetches payloads over port 443
  • Vector: Compromised GitHub repositories, malicious npm/NuGet packages, and hijacked maintainer accounts
  • ARTEX AI-powered penetration testing: Autonomous agents discover and exploit vulnerabilities, escalate privileges, and steal data, integrating external models such as Claude, GPT, DeepSeek, and Grok
  • Vector: Internet-facing ARTEX management consoles and agent-driven attacks against organizations
  • Browser management abuse (SYS010): Attackers force Chrome, Edge, and Firefox to install malicious extensions via admin policies and UAC fatigue, then steal session cookies and Gmail/Outlook email
  • Vector: Malvertising disguised as animated wallpaper installers
  • Trojanized software installers (Q-Dir/DesktopOK): Legitimate installers are replaced with versions that drop a Python RAT and establish persistence via a scheduled task impersonating Microsoft Edge
  • Vector: Compromised official software download and update channel

Threat Actor Activities

  • North Korea-linked PolinRider (sub-cluster of Contagious Interview): Compromised over 7,600 GitHub repositories to distribute a Python loader and infostealer; activity traced back to February 2025; distribution channels include fraudulent recruitment (BlockNovas, AccuraSoftHire, HuntRole), malicious open-source packages, and hijacked maintainer accounts force-pushing malicious commits
  • Campaign: PolinRider; targets developers and corporate environments via software supply chain
  • Suspected Vietnam-linked WeaveLotus / RedOps: Five confirmed intrusions in Thailand and the Philippines plus reconnaissance against Indonesian government organizations; initial access via web application vulnerabilities (GeoServer CVE-2024-36401, osTicket CVE-2021-42235) and default credentials; persistent access through reverse SSH tunnels; exfiltration of government records
  • Campaign: RedOps; targets Southeast Asian military, government, and legislative organizations
  • Iranian group Volant Manticore: Previously undocumented threat group targeting Cypriot organizations for intelligence gathering on behalf of Tehran
  • ARTEX users: Multiple threat actors, including Chinese state-aligned Storm-0940 (ConnectWise Cloud Backup attack, 162 compromised Microsoft 365 tenants) and Chinese group Vapor Panda (cyberespionage across 200+ organizations in 14 countries), used ARTEX for automated attacks since at least August 2026
  • ShinyHunters: Extortion group that breached FBI systems via an unpatched Oracle PeopleSoft vulnerability on FBIJobs.gov; also linked to vishing-based SSO credential theft
  • Unattributed operators: Trojanized Q-Dir and DesktopOK installers (Chinese language comments in source code) delivering a Python RAT; Microsoft Store app delivering Vinci RAT; SYS010 and Remus infostealers stealing Gmail/Outlook email via malicious browser extensions; GoodGuys phishing kit stealing corporate Google and Okta credentials through fake paid interview invitations
