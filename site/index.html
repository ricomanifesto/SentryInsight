Exploitation ReportNovember 21, 2026

Executive Summary

Critical actively exploited zero-day vulnerabilities dominated recent threat activity, including VMware vCenter Server authentication bypass (CVE-2026-123890) exploited by the China-nexus Armory Castle group since September 2026 and patched on November 19, and F5 BIG-IP APM remote code execution (CVE-2026-94127) actively exploited in zero-day attacks. CISA added SAP NetWeaver Enterprise Portal (CVE-2025-42884) to its Known Exploited Vulnerabilities catalog citing active exploitation evidence, alongside Apache Roller, Cisco Expressway, and VMware vCenter flaws.

Additional exploitation activity includes potential in-the-wild exploitation of Cisco Expressway hard-coded credentials (CVE-2026-76466) observed by F6 against a Russian organization following public PoC release, and autonomous AI agent campaigns using the Cairn platform to discover and exploit a MONAI Label path traversal zero-day. Unpatched issues include the FastUnlock Windows lock screen bypass requiring physical access, with no evidence of real-world exploitation, and the Meta Muse AI agent vulnerability demonstrated in a laboratory setting before patches were applied.

Threat actor activity centers on Armory Castle (formerly UNC5221), which chained BeyondTrust Remote Support (CVE-2026-102764) and VMware vCenter zero-days in a single intrusion campaign deploying custom malware including BONESAW, SAWSNAKE, SLIMSAVAGE, and LAZYBONES. Chinese-nexus actors also leveraged autonomous AI agents against East Asian educational institutions, while Android malware frameworks Bazuka and ArcticRAT integrated LLM capabilities for victim management and data exfiltration.

Affected Systems and Products

  • VMware vCenter Server: VMware Directory Service authentication bypass affects vCenter Server deployments including standalone and VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform, and VMware Telco Cloud Infrastructure; also affects SDDC Manager and VMware Tools for Windows.
  • BeyondTrust Remote Support: Remote support appliances exploited by Armory Castle as an initial access vector in a broader intrusion campaign.
  • SAP NetWeaver Enterprise Portal: Enterprise Portal systems vulnerable to JNDI injection via data query logic; patched in November 2025.
  • Cisco Expressway Series: Expressway devices running Release X14 and earlier, and Release X15.5.3 and earlier, vulnerable to hard-coded credential exploitation via database service RPC commands.
  • F5 BIG-IP APM: BIG-IP Access Policy Manager and iRules programmable scripting feature vulnerable to stack-based buffer overflow flaws enabling remote code execution and denial of service.
  • WhatsApp Mobile and Desktop: WhatsApp for Android, WhatsApp Business for Android, WhatsApp for iOS, WhatsApp Business for iOS, and WhatsApp for Mac Desktop affected by certificate verification and other flaws.
  • Ivanti Connect Secure: Enterprise VPN appliances previously exploited by Armory Castle for initial access and persistence.
  • Meta Muse: Meta's personal AI agent running on individual cloud computers with connected account credentials and conversation memories.
  • Windows Computers: Locked Windows computers with physical access exposure and Microsoft accounts accessible through lock screen recovery options.

Attack Vectors and Techniques

  • Authentication Bypass: Unauthenticated network attacker bypasses VMware Directory Service authentication via DCE/RPC to establish an administrator session on vCenter Server.
  • Hard-Coded Credentials: Attacker with persistent cookies connects to Cisco Expressway database service and invokes RPC commands to execute arbitrary OS commands as root.
  • Zero-Day Remote Code Execution: F5 BIG-IP APM stack-based buffer overflow exploited remotely without authentication to execute arbitrary code and cause denial of service via TMM process termination.
  • Path Traversal: Autonomous AI agents discovered a path traversal flaw in MONAI Label enabling arbitrary file writes and deployment of a Python reverse shell for root access.
  • Malware Overlays: Bazuka Android malware uses screenshot overlays of home/lock screens to cover malicious activities, and phishing HTML overlays for credential theft.
  • Accessibility Services Abuse: Bazuka and ArcticRAT abuse Android accessibility services to request and grant permissions automatically, enable Wireless Debugging, and capture lock screen PINs.
  • Hidden VNC and Black Screen Overlay: ArcticRAT uses Hidden VNC for remote control and draws a black un-dismissible view with zero brightness to conceal background operations from victims.
  • Physical Access Lock Screen Bypass: FastUnlock uses Windows Narrator to navigate a locked screen and launch programs in a limited account without signing in.
  • DLL Sideloading: ROMULUS ClickFix delivers malware via signed IBM SPSS IDE executable and malicious MSI installers executing DLL sideloading chains to run embedded shellcode.
  • Golden SAML Attacks: SAWSNAKE utility enables SAML authentication bypass and session cookie generation to forge authentication tokens and bypass multi-factor authentication.

Threat Actor Activities

  • Armory Castle (formerly UNC5221): Suspected China-nexus cyber espionage group exploited CVE-2026-123890 in VMware vCenter in early September 2026 and CVE-2026-102764 in BeyondTrust Remote Support since late August 2026. The group deployed BONESAW (Golang exploitation tool), SAWSNAKE (Golden SAML utility), SLIMSAVAGE and CAGEMATCH (JSP web shells), BEARBONES (C backdoor), and LAZYBONES (Slack C2 backdoor) to move from Remote Support appliances through internal Linux systems to VMware vCenter, ultimately accessing ESXi hosts and extracting virtual machine data including Active Directory databases.
  • Chinese-Nexus AI Agent Operator: Between September 8 and 10, 2026, a suspected Chinese-linked threat actor used the autonomous Cairn AI agent platform to discover and exploit a zero-day in MONAI Label, targeting East Asian educational institutions outside China. The agents obtained shell access on a medical imaging server within 11 minutes of discovering the vulnerability.
  • Unattributed Cisco Expressway Exploiters: Unknown threat actors exploited CVE-2026-76466 to breach a Russian organization, compromising two internet-facing Cisco Expressway devices and two additional internal cluster nodes, using custom Python scripts possibly developed with AI assistance to scan networks, access SMB resources, SQL Server, WinRM, and GitLab repositories.
  • Bazuka Operators: Unknown actors operating the Bazuka Android malware framework with LLM-integrated control panel, distributed via traffers and Google Play Store, masquerading as premium TikTok and other popular apps; panel UI elements displayed in English and Russian.
  • ArcticRAT Operators: Unknown actors deploying ArcticRAT Android RAT with 129 commands and LLM API integration for financial data exfiltration, distributed through malicious sites impersonating Google Play listings via malvertising, smishing, and third-party forums.
