Exploitation ReportNovember 24, 2026

Executive Summary

Threat actors exploited a critical ConnectWise ScreenConnect client flaw, tracked as CVE-2026-84869, to hijack managed service provider technician workstations without warning. Observed activity between October 20 and November 16, 2026 included guest-pushed batch files, MSI installers masquerading as Windows updates, and rogue ScreenConnect clients connecting to attacker-controlled relays across at least 118 self-hosted servers.

A suspected China-nexus espionage group, Armory Castle, was attributed to zero-day exploitation of a VMware vCenter authentication bypass flaw, CVE-2026-123890, in early September 2026. CISA also added N-able MailAssure CVE-2026-134624 and MONAI Label CVE-2026-133968 to its Known Exploited Vulnerabilities catalog, citing evidence of active exploitation. Several additional recently patched flaws in binary-parser, WHMCS, and VMware vCenter remain assessed with unknown exploitation status pending further evidence.

Affected Systems and Products

  • ConnectWise ScreenConnect: Self-hosted ScreenConnect servers used by managed service providers; technician host clients updated to 26.6.5 or later are advised.
  • N-able MailAssure and SpamExperts Hosted Cloud: Email filtering service for MSPs; hosted cloud build 20261121.1943 is the fixed build.
  • MONAI Label: Open-source medical imaging AI application; deployed on university servers in East Asia.
  • VMware vCenter Server: VMware Directory Service component across vCenter 7.0, 8.0, and VMware Cloud Foundation/vSphere Foundation versions.
  • binary-parser: Node.js library versions prior to 2.3.1.
  • Langflow: AI application infrastructure targeted by AI agent campaigns.
  • WHMCS: Billing and automation platform for web hosting companies; versions 8.0 to 8.12, 9.0, 9.1 series affected by various flaws.

Attack Vectors and Techniques

  • Guest-pushed payload execution: A malicious ScreenConnect guest pushes a file to a technician's machine and causes the technician's own client to run it without a prompt, upon joining a session.
  • SSRF via LDAP sync connection check: An authenticated API user causes the server to connect to arbitrary internal hosts and ports to discover reachable internal services and send crafted data.
  • Path traversal and arbitrary file write: An unauthenticated remote attacker writes files outside the intended datastore directory in MONAI Label, potentially achieving remote code execution.
  • Authentication bypass in VMware Directory Service: A malicious actor with network access to vCenter bypasses authentication to gain unauthorized access to the system.
  • Arbitrary file write via archive processing: Processing certain archives in VMware vCenter could be exploited to achieve code execution on the appliance.
  • JavaScript injection through unvalidated parser options: Attackers controlling parser definitions supply crafted string values that execute arbitrary JavaScript in the Node.js process when the parser is compiled.
  • AI agent-driven exploitation: AI-powered problem-solving engines plan and execute hacking operations autonomously, including brute-forcing Redis instances and exploiting zero-days in about 11 minutes to write files and spawn reverse shells.

Threat Actor Activities

  • Armory Castle (formerly UNC5221): Suspected China-nexus cyber espionage group attributed to zero-day exploitation of VMware vCenter CVE-2026-123890 in early September 2026; previously used a BeyondTrust zero-day to breach edge appliances and deploy backdoors on Linux machines.
  • Webworm: China-aligned nation-state group using a modified SoftEther VPN Bridge (vpnbridge_x64.exe version 4.44, build 9807) rebranded as NtMonitor VPN to establish covert remote access while evading detection signatures.
  • O-UNC-053 / INCEPTION: Threat cluster affiliated with ShinyHunters conducting voice phishing (vishing) attacks using legal-themed domains to steal credentials and MFA codes, targeting technology, healthcare, financial services, and other sectors.
  • Cold Relic: Russian cyberespionage group leveraging cloud breaches to impersonate employees and conduct social engineering attacks against trusted partner organizations.
  • Unknown actor (CAIRN / ARTEX): AI-driven threat actors exploiting MONAI Label CVE-2026-133968 and other flaws to obtain shell access, targeting universities in East Asia and AWS environments for financial data theft.
