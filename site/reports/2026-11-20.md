# Exploitation Report

## Executive Summary

A critical VMware vCenter Server authentication bypass tracked as CVE-2026-123890 was exploited as a zero-day by the suspected China-nexus espionage group Armory Castle beginning in September 2026, with Mandiant documenting intrusion activity before Broadcom's November 19 patch release. The flaw permits unauthenticated attackers with network access to bypass authentication and obtain administrative access to vCenter and the virtual machines it manages. Exploitation status is assessed as unknown in the supplied evidence despite detailed campaign reporting.

F5 disclosed that CVE-2026-94127, a critical BIG-IP APM vulnerability, is being actively exploited in zero-day remote code execution attacks. Separately, Cisco Expressway CVE-2026-76466 is assessed as potential exploitation following public proof-of-concept release and observed in-the-wild activity against a Russian organization. Multiple PHP critical flaws including CVE-2026-115560 were patched on November 19, with exploitation status unknown.

The Armory Castle campaign also involved prior exploitation activity linked to CVE-2026-102764 in BeyondTrust Remote Support and historical use of CVE-2025-22457 in Ivanti Connect Secure, demonstrating a pattern of zero-day chaining against enterprise infrastructure. Defenders should prioritize patching and review their virtualization, application delivery, and remote access environments.

## Active Exploitation Details

### VMware vCenter Server Authentication Bypass (CVE-2026-123890)
- **Description**: A critical authentication bypass vulnerability in the VMware Directory Service allows unauthenticated attackers with network access to bypass authentication and gain unauthorized access to vCenter Server.
- **Impact**: Attackers can obtain administrative access to vCenter, execute arbitrary commands, and acquire files including the data.mdb database, potentially compromising entire virtualized environments.

## Affected Systems and Products

- **VMware vCenter Server**: VMware Directory Service component; affected platforms include vCenter Server, VMware Cloud Foundation, VMware vSphere Foundation, VMware Telco Cloud Platform, and VMware Telco Cloud Infrastructure; standalone and clustered deployments including Enhanced Linked Mode environments

- **Cisco Expressway**: Cisco Expressway Series devices running Release X14 and earlier, and Release X15.5.3 and earlier; internet-facing clustering configurations with TLS Verify Mode enabled
- **PHP**: PHP core engine and session handling across supported branches 8.2.x, 8.3.x, 8.4.x, and 8.5.x; deployments using file-based session storage
- **BeyondTrust Remote Support**: Remote Support appliances targeted in lateral movement campaigns
- **Ivanti Connect Secure**: Enterprise remote access appliances previously targeted in intrusion campaigns

## Attack Vectors and Techniques

- **Authentication Bypass via DCE/RPC**: Unauthenticated attacker with network access exploits the VMware Directory Service (vmdird) RPC interface to establish an authenticated administrator session via SRP-6a session key disclosure
- **Zero-Day Remote Code Execution**: Attackers exploit BIG-IP APM stack-based buffer overflow flaws to terminate the TMM process and execute arbitrary code remotely on vulnerable configurations
- **Persistent Cookie Abuse**: Attackers with possession of persistent cookies connect to the Cisco Expressway database service and invoke RPC commands to execute arbitrary OS commands as root
- **Session Write Interruption**: PHP file-based session writes interrupted mid-operation can leave mixed session state, enabling deserialization of attacker-influenced objects when session_start() is called
- **Campaign Chaining**: Attackers first compromise BeyondTrust Remote Support appliances, move laterally to internal Linux systems, deploy web shells (SLIMSAVAGE, CAGEMATCH), then target VMware infrastructure using custom Golang tool BONESAW
- **Golden SAML Attacks**: SAWSNAKE utility forges SAML tokens and session cookies to bypass multi-factor authentication and impersonate legitimate users in VMware environments

## Threat Actor Activities

- **Armory Castle (formerly UNC5221)**: Suspected China-nexus cyber espionage group known for exploiting zero-day vulnerabilities in enterprise network appliances including Citrix NetScaler, Ivanti Connect Secure, and VMware vCenter; breached corporate networks and deployed custom malware including BONESAW, SAWSNAKE, BEARBONES, LAZYBONES, CAGEMATCH, and SLIMSAVAGE
- **Armory Castle VMware Campaign**: Exploited CVE-2026-123890 in early September 2026 using BONESAW to create vCenter SSO administrator accounts, steal directory databases, extract SAML signing keys, and conduct Golden SAML attacks; moved laterally to ESXi hosts and extracted Windows Active Directory database files
- **Chinese-nexus Cairn Actor**: Used autonomous AI agent platform "Cairn" between September 8 and 10, 2026 to discover and exploit a path traversal zero-day in MONAI Label, targeting East Asian educational institutions outside China
- **Unattributed Cisco Expressway Actors**: Exploited CVE-2026-76466 to breach a Russian organization, compromise internet-facing Expressway devices, move laterally to internal cluster nodes, and exfiltrate credentials using custom Python scripts possibly developed with AI assistance
- **Scattered Spider**: Previously breached Transport for London's network in 2024, stole customer data, disrupted online services including Oyster refunds; two members pleaded guilty in June 2026 and were sentenced to five years and six months in prison
