# Exploitation Report

## Executive Summary

The most critical exploitation activity this period involves two actively exploited vulnerabilities already in vendor patches and CISA's Known Exploited Vulnerabilities catalog. Cisco BroadWorks OCI XML Parser (CVE-2026-20320), an unauthenticated remote XXE flaw, is being exploited in the wild as part of an autonomous AI-driven campaign (Operation Snowball) targeting a European telecommunications provider and related organizations, with CISA ordering federal remediation by November 24, 2026. Microsoft Outlook (CVE-2026-124194) is also actively exploited; a spoofing flaw lets attackers capture NTLMv2 hashes when a victim opens a specially crafted message file, and Microsoft has released patches with CISA requiring federal application by the same deadline.

Separately, several recently patched zero-days and critical flaws carry unknown exploitation status under the supplied evidence assessment and require defender attention. These include Zoom Workplace for Windows privilege escalation flaws (CVE-2026-108186, CVE-2026-108187, CVE-2026-53412), a Chrome zero-day resolved in Chrome 157.0.8103.50 (CVE-2026-125350), multiple N-able N-central zero-days patched in N-central 2026.4 HF2, and Qlik Sense flaws historically linked to CACTUS ransomware (CVE-2023-41265, CVE-2023-41266, CVE-2023-48365). Because the scoped assessments for these are unknown, this report does not assert active exploitation for them; it records patch availability and neutral status per the supplied evidence.

Notable threat activity centers on agentic AI tooling and ransomware. An unknown Chinese-speaking actor used a jailbroken DeepSeek Flash model in an autonomous agent chain against Cisco BroadWorks, while AntiFox and ARTEX agentic penetration-testing frameworks have been observed stealing AWS credentials and pivoting into cloud environments. The Qilin ransomware group, administered by an individual deanonymized as a St. Petersburg resident, remains highly active with over 365 victims in three months and double-extortion tactics. Defenders should prioritize patching the confirmed actively exploited CVEs first, then address the unknown-status critical flaws based on exposure.

## Active Exploitation Details

### Cisco BroadWorks OCI XML Parser XXE Vulnerability (CVE-2026-20320)
- **Description**: An improper restriction of XML External Entity (XXE) reference weakness in the Open Client Interface (OCI) XML Parser of Cisco BroadWorks that can allow unauthenticated, remote attackers to read sensitive configuration information from vulnerable systems by sending maliciously crafted XML messages to the Open Client Interface - Provisioning (OCI-P) service. XML entries are improperly parsed because external entity resolution is allowed by default.
- **Impact**: Attackers can read arbitrary files from the server filesystem via a crafted OCI request to port 2208 with no prior authentication, including the BroadWorks system identity private key, SSL credential sets, and additional private keys, enabling impersonation of the XSP in inter-component communication and exposure of sensitive configuration information.
- **Status**: Cisco patched the bug in August 2026. CISA flagged CVE-2026-20320 as actively exploited, added it to the Known Exploited Vulnerabilities (KEV) Catalog, and ordered FCEB agencies to secure systems within two weeks by November 24, 2026 under Binding Operational Directive (BOD) 26-04. A patch is available.
- **Severity**: high
- **Exploitation Status**: active
- **Action**: patch
- **CVE IDs**: CVE-2026-20320
- **Reporting**: [Bleeping Computer — CISA flags Cisco BroadWorks flaw as actively exploited in attacks](https://www.bleepingcomputer.com/news/security/cisa-flags-cisco-broadworks-flaw-as-actively-exploited-in-attacks/), [The Hacker News — Cisco BroadWorks and Openwave Flaws Actively Exploited Despite Available Patches](https://thehackernews.com/2026/11/cisco-broadworks-and-openwave-flaws.html)
- **Affected Versions**: Unresolved from supplied sources.
- **Affected Versions Status**: unresolved
- **Exceptions**: None stated in supplied sources.
- **Recommended Actions**: CISA urged all security teams, including those in the private sector, to prioritize patches for this vulnerability to defend their networks against ongoing attacks; FCEB agencies must secure their systems within two weeks, by November 24, as mandated by Binding Operational Directive (BOD) 26-04.

### Microsoft Outlook Spoofing Zero-Day (CVE-2026-124194)
- **Description**: A Moderate-severity spoofing bug in Microsoft Outlook where the product UI does not warn users of unsafe actions, allowing an unauthorized attacker to perform spoofing over a network by sending a specially crafted message file and persuading a target to open it. This causes Outlook to connect to an attacker-controlled network location without displaying the usual external-content warning, potentially disclosing authentication information such as an NTLMv2 hash.
- **Impact**: Disclosure of NTLMv2 hashes that could be used to impersonate the user, read their data, and move to other systems they can reach. Exploitation requires network connectivity and user interaction. Affects Microsoft 365 Apps for Enterprise and editions of Microsoft Office.
- **Status**: Microsoft flagged the flaw as actively exploited and released patches in the November 2026 Patch Tuesday. CISA added it to the KEV catalog, requiring federal agencies to apply the fix by November 24, 2026. No specific threat actor has been attributed.
- **Severity**: medium
- **Exploitation Status**: active
- **Action**: patch
- **CVE IDs**: CVE-2026-124194

## Attack Vectors and Techniques

- **XML External Entity (XXE) injection**: Crafted OCI XML messages sent to the OCI-P service on port 2208 cause the Cisco BroadWorks XML parser to read arbitrary files from the server filesystem without authentication (CVE-2026-20320).
- **Outlook spoofing and NTLMv2 hash disclosure**: A specially crafted message file tricks a recipient into opening it, causing Outlook to connect to an attacker-controlled network location without an external-content warning and disclose NTLMv2 hashes (CVE-2026-124194).
- **Network-based privilege escalation**: Improper input validation and origin validation flaws allow unauthenticated remote attackers to escalate privileges via network access against Zoom Workplace for Windows (CVE-2026-108186, CVE-2026-108187, CVE-2026-53412).
- **Agentic autonomous exploitation**: AI agents (e.g., the Operation Snowball framework built on a jailbroken DeepSeek Flash model, and AntiFox/ARTEX platforms) autonomously perform reconnaissance, attack-surface discovery, exploitation, credential harvesting, and post-exploitation at machine speed.
- **Cross-account IAM trust abuse**: Compromised third-party IAM credentials are used to assume cross-account roles in customer AWS environments, enumerate S3 buckets and secrets, and exfiltrate data (Qubole campaign).
- **Qlik Sense exploitation chain**: HTTP tunneling, path traversal, and unauthenticated remote code execution flaws used to establish initial footholds and deploy persistence tooling (CVE-2023-41265, CVE-2023-41266, CVE-2023-48365).
- **eBPF rootkits and magic packets**: Kernel-level implants activated by crafted TCP packets and window sizes, hiding processes via getdents64 hooks, with related BPF verifier research (CVE-2017-16995).

## Threat Actor Activities

- **Qilin ransomware group (admin "Haise", linked to Aleksey Mikhailovich Yakovtsev of St. Petersburg, Russia)**: The world's most active ransomware-as-a-service affiliate program, claiming at least 365 victim organizations in three months, using double extortion (data theft plus encryption), and collaborating with English-speaking affiliates and groups such as Scattered Spider and RansomHub.
- **Operation Snowball (unknown Chinese-speaking threat actor)**: Leveraged an autonomous AI agent built with a jailbroken DeepSeek Flash model to exploit CVE-2026-20320 against a European telecommunications provider and 13 organizations using its data centers and cloud infrastructure; extracted system identity private keys, SSL credentials, subscriber billing records, and device records over two weeks, using Sliver, Chisel, and Behinder web shells for persistence.
- **AntiFox / ARTEX agentic operators**: Agentic penetration-testing platforms hosted on Alibaba Cloud used to steal AWS credentials, pivot into AWS environments, harvest secrets from Secrets Manager and S3, and deploy ASPX webshells on IIS servers; ARTEX has also been linked to the Chinese group Vapor Panda targeting over 200 organizations across 14 countries and to attacks on South Korean banks.
- **Black October campaign**: A wave of attacks against AI developer platforms including Railway, Northflank, OpenCode, Warp, and Lightning AI, with threat actors hunting for stored AI provider credentials, API keys, tokens, and environment variables for resale or AI model distillation.
- **Cactus ransomware**: Previously exploited Qlik Sense flaws (CVE-2023-41265, CVE-2023-41266, CVE-2023-48365) in November 2023 to obtain initial access and deploy ManageEngine UEMS, AnyDesk, and Plink for persistence and remote control.
