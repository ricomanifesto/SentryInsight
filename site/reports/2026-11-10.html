Exploitation ReportNovember 10, 2026

Executive Summary

This reporting period includes multiple recently patched and actively discussed vulnerabilities with exploitation statuses assessed as unknown or potential based on the supplied sources. CISA added four flaws—CVE-2026-123218, CVE-2026-116779, CVE-2026-123158, and CVE-2026-102895—to its Known Exploited Vulnerabilities catalog citing active exploitation evidence, while Google patched Chrome zero-day CVE-2026-125350 alongside previously addressed Chrome flaws including CVE-2026-2441, CVE-2026-3909, CVE-2026-3910, CVE-2026-5281, CVE-2026-11645, CVE-2026-85046, and CVE-2026-87491. Apple addressed iMessage flaws CVE-2026-113961 and CVE-2026-113960 and Brotli flaw CVE-2026-111497. For all CVEs in this report, the supplied exploitation assessment assigns an unknown status unless explicitly noted otherwise; no finding should be interpreted as confirmed active exploitation solely from article headings or related narrative.

Separately, several incidents and threat campaigns are reported without associated CVE identifiers. France attributed October sabotage attacks against approximately 700 French retail refrigeration controllers to Iranian state-backed unit Shahid Kaveh, resulting in food losses and fires. The Turla group was observed using the Cereal toolset against Microsoft Exchange servers in Kazakhstan and Romania to harvest email. Blind Eagle (APT-C-36) conducted a Latin America phishing campaign using fake court notices to deliver an AsyncRAT/DCRat-lineage remote access trojan. N-able took N-central environments offline after public disclosure of more than 30 alleged zero-days under the Able2Shell designation, with vendor statements indicating no observed active exploitation at the time of reporting. Additionally, Binance warned of the iOS worse_query sandbox escape (CVE-2026-113963), assessed as potential exploitation, with proof-of-public code available but no confirmed attacks or thefts reported.

Reporting

  • Bleeping Computer — Google patches eighth Chrome zero-day exploited in attacks this year · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: chromereleases.googleblog.com

  • Description: High-severity use-after-free bug in the XML component of Google Chrome, occurring when the XML parser processes data, deletes an object from memory, but fails to clear the pointer referencing that object.
  • Impact: Successful exploitation could allow data corruption, program crashes, or arbitrary code execution when the browser later attempts to use the freed memory space.
  • Status: Patch available in Chrome versions 157.0.8103.50/.51 for Windows and macOS, and 157.0.8103.50 for Linux. Google acknowledged awareness that an exploit exists in the wild but did not disclose additional incident details; exploitation status assessed as unknown per supplied contract.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: Users are advised to update their Chrome browser to versions 157.0.8103.50/.51 for Windows and Apple macOS, and 157.0.8103.50 for Linux; users of Chromium-based browsers such as Microsoft Edge, Brave, Opera, and Vivaldi should apply fixes as they become available.

Attack Vectors and Techniques

  • Chrome XML use-after-free: Malicious web content triggers memory corruption in Chrome's XML component when the parser frees an object but fails to clear a dangling pointer, potentially leading to arbitrary code execution.
  • OpenSSH SSHole authentication bypass: Unexpected status codes or return values in OpenBSD OpenSSH on Linux allow authentication bypass; post-exploitation includes modification of SSH authorized_keys, credential access, and deployment of the TAC Agent C2.
  • iOS worse_query sandbox escape: A malicious or sideloaded app uses App Group containers to cross iOS sandbox boundaries and read, export, edit, or delete other apps' data without a jailbreak or kernel exploit.
  • AhsayCBS authentication bypass and command execution: Chained exploitation bypasses authentication and executes arbitrary commands to deploy JSP web shells, XMRig miners, tunneling tools, and a sandbox-evading Python backdoor.
  • iMessage group chat flaws: Authorization and message-history access issues allow unauthorized participants to join group chats or read messages sent before they joined.
  • Turla Cereal email harvesting: CerealBox injectes into Microsoft Exchange EdgeTransport.exe to hijack transport agents and selectively harvest emails with DOC, DOCX, or PDF attachments; commands are delivered as compiled .NET programs executed in memory without external C2 infrastructure.
  • Blind Eagle phishing: Weaponized SVG/XHTML attachments use HTML smuggling to assemble ZIP payloads in-browser; JavaScript droppers perform reconnaissance, bypass AMSI/ETW, and launch an AsyncRAT/DCRat-lineage trojan in memory via PowerShell.

Threat Actor Activities

  • BYOD ransomware gang: Claimed responsibility for an attack on Vanderbilt University, alleging encryption of databases and theft of sensitive student, employee, and research data including over 1 million SSNs; operated a data leak site and ransom note, though Vanderbilt did not officially confirm involvement.
  • Shahid Kaveh (IRGC): Iranian state-backed cyber-offensive unit attributed by France for October attacks against approximately 700 French supermarket refrigeration controllers, causing food losses and at least 15 fires; associated hacktivist identities include CyberAveng3rs, Soldiers of Solomon, Mr. Soul, and Cyber Isnaad Front.
  • Turla (Snake, Secret Blizzard, Waterbug): Russian state-backed group using the Cereal toolset against government Exchange servers in Kazakhstan and Romania in late 2025, selectively collecting email involving NATO and EU representatives.
  • Blind Eagle (APT-C-36): Spanish-speaking group active since 2018 conducting a Latin America campaign with Portuguese and Spanish judicial-themed phishing lures, delivering an AsyncRAT fork with DCRat lineage; observed nearly 3,300 malicious emails between late October and early November 2026, with Colombia as a priority target.
  • Financially motivated LLMjacking actors: Cybercriminal groups targeting AI infrastructure to steal LLM API keys and tokens for resale through illicit routing gateways; linked to Fireworks AI breaches involving development machine access and exposure of billing data and incomplete model weights.
  • Unknown actor GT10: Observed deploying TAC Agent, a Python-based command-and-control agent, in connection with OpenSSH SSHole exploitation attempts.
  • watchTowr: Reported observing exploitation attempts against N-able N-central honeypots following publication of Able2Shell proof-of-concept code; N-able confirmed scanning activity but no evidence of successful customer exploitation at the time of reporting.
