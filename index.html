Exploitation ReportNovember 26, 2026

Executive Summary

Critical exploitation activity centers on a Drupal core installer vulnerability tracked as CVE-2026-132165, assessed as potential exploitation status, which allows unauthenticated attackers to attempt site reinstallation leading to remote code execution or site takeover. Patches are available for supported Drupal versions, while end-of-life branches remain without fixes. Multiple GeoServer vulnerabilities, including CVE-2026-129245 with potential exploitation chaining and CVE-2026-120705 and CVE-2026-129244 with unknown exploitation status, expose unauthenticated remote code execution chains against publicly accessible instances.

Additional critical infrastructure and network appliance flaws are under assessment. Danfoss refrigeration controllers have been compromised in attacks against European supermarkets, with CVE-2026-129713 assessed as unknown exploitation status and no patch currently available. PHP2Shell vulnerabilities CVE-2026-109618 and CVE-2026-109619 are chained with the Fragnesia kernel flaw CVE-2026-46300 to target Palo Alto Networks and Check Point devices, with exploitation status assessed as unknown across the cited sources.

Threat activity includes AI-driven offensive campaigns targeting Check Point Security Management servers, Silk Typhoon targeting U.S. federal agencies, and Iranian IRGC-linked units attributed to supermarket refrigeration attacks. Supply chain risks involve malicious NuGet packages targeting .NET developers and blocked backdoored WordPress plugins.

Earlier reporting
  • CVE-2026-132165. Reported on 1 earlier report date since November 25: Nov 25. This finding and the November 25 finding cite the same sources. The November 25 finding had the same labels.
  • Description: A critical vulnerability in Drupal core's install.php allows unauthenticated attackers to attempt reinstallation of Drupal on existing sites, leading to remote code execution or complete site takeover by abusing server resource limits and SQLite database handling.
  • Impact: Attackers can hijack vulnerable Drupal sites, create administrator-controlled accounts, and execute arbitrary PHP code on affected servers.
  • Status: Exploitation status is potential. Patches are available for Drupal 11.4.x, 11.3.x, and 10.6.x; Drupal 11.0.x to 11.2.x and 10.5.x and below are end-of-life with no fix.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Site owners who have already secured the installer ("install.php") are not impacted.
  • Recommended Actions: Websites using the paid Drupal Steward Web Application Firewall (WAF) service are already protected from known attack vectors, but admins are still advised to upgrade to the latest available Drupal version in case other attack vectors are discovered. Those who can't immediately upgrade should block access to /core/install.php in the web server configuration or the .htaccess file in the web root to secure the Drupal installer.; After updating to the latest supported versions, it's recommended to run "update.php" to fix existing production sites in this state and secure the Drupal installer on all new and existing sites.

Affected Systems and Products

  • Drupal Core: Content management system used by government entities, research universities, and enterprise organizations; affected versions include end-of-life branches Drupal 11.0.x to 11.2.x and 10.5.x and below with no fix
  • GeoServer: Open-source geospatial server; publicly exposed instances running vulnerable versions of gs-wfs-core, gs-ows, gt-metadata, gs-main, and gs-sec-jdbc components
  • HPE Juniper Session Smart Router and Conductor: Network infrastructure devices vulnerable to command injection via salt minion ID
  • Vates Xen Orchestra: Virtualization management platform vulnerable to authentication bypass via empty JSON object tokens
  • Danfoss AK-SM 800A Series: Commercial refrigeration, HVAC, and lighting controllers used in supermarkets and food retailers worldwide, including 820A, 850A, and 880A models
  • Palo Alto Networks PAN-OS: Firewalls with management interfaces exposed to the internet, versions 10.2, 11.1, 11.2, 12.1, and 12.2
  • Check Point Security Management Servers: Management servers across financial services, energy, government, transportation, mining, engineering, and manufacturing sectors
  • Rejetto HFS: HTTP File Server instances targeted as initial access relays

Attack Vectors and Techniques

  • Drupal Installer Reinstallation: Attackers exhaust server resources (EMFILE, database connections, TCP source ports) to trick Drupal into believing a site is not installed, then use install.php to create administrator accounts and execute arbitrary PHP via SQLite database files with .php extensions
  • GeoServer WFS Exploitation: Unauthenticated WFS GetFeatureById XML injection reads local files, and stored query exceptions disclose data directory paths, chaining to administrator session forgery and code execution
  • PHP2Shell Chaining: Unauthenticated PHP remote code execution is chained with Linux kernel XFRM privilege escalation (Fragnesia) to deploy webshells and execute commands as root on network devices
  • AI-Powered Penetration Testing: Autonomous AI agents (ARTEX AI, CyberStrikeAI, DeepSeek Harness, PentAGI) chain vulnerabilities, misconfigurations, and compromised credentials to compromise exposed endpoints and move laterally
  • AiTM Phishing via DOM Mirroring: Attacker browsers mirror legitimate sign-in pages in real time, bypassing bot checks and safe browsing controls to capture corporate Google and Microsoft credentials
  • Malvertising Browser Management: Malicious ads impersonating wallpaper applications abuse enterprise browser management policies to force-install malicious extensions that steal session cookies and email content

Threat Actor Activities

  • Silk Typhoon: Chinese state-backed hacking group that hacked the Office of Foreign Assets Control (OFAC), breached the Treasury's Office of Financial Research, and infiltrated the Committee on Foreign Investment in the United States
  • ShinyHunters: Extortion group that claimed to breach the FBI's recruitment website FBIJobs.gov, leading to arrests of multiple suspected members including a Canadian cybersecurity executive
  • Shahid Kaveh (Cyber Aveng3rs / Cyber Isnaad Front): Iranian cyber unit affiliated with the Islamic Revolutionary Guard Corps (IRGC), attributed by France to October 2026 attacks on French supermarket refrigeration systems
  • Unknown Actor (GreyNoise Threat 13 / GT13): Unattributed threat actor using AI-driven offensive tooling to compromise 24 Check Point Security Management servers across 22 organizations globally between October 17 and November 2, 2026, using 99 IP addresses and tools including Nmap, Chisel, Impacket, and Paramiko
  • Unknown Attackers (CIA/ODNI/NGIA): Breached an open-source intelligence analysis system using the ARTEX AI-powered penetration testing framework; no classified data or systems were exposed
  • Unknown Attackers (FinCEN): Unauthorized access to a limited subset of FinCEN systems; agency took systems offline and is working with FBI, CISA, and third-party forensic examiners
