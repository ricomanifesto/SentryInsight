Executive Summary

Recently patched vulnerabilities and active exploitation campaigns dominate the current threat landscape. A now-patched flaw in Apple's audio service (CVE-2026-65339) allowed applications to record microphone audio even after users denied microphone permission, though neither Apple nor the researchers confirmed exploitation in the wild. The flaw bypassed Transparency, Consent, and Control (TCC) checks by having the audiomxd service trust an app-supplied audit token naming itself.

ConnectWise ScreenConnect faces potential exploitation through CVE-2026-84869, a critical client-side flaw (CVSS 9.9) leveraged by the SCKit malware toolkit in a worm-like propagation technique targeting technician workstations during remote support sessions. Separately, N-able has patched 17 N-central vulnerabilities in Hotfix 3, while related 4EverAble2Shell flaws have been actively exploited to deploy cryptocurrency miners on vulnerable servers.

Broader campaign activity includes Operation ShadowCloud, which deploys GitDoor and GraphDoor backdoors via GitHub and SharePoint against government targets in Asia and Africa, and the Trigram campaign, assessed with high confidence as a North Korea-linked operation targeting developers across AI, blockchain, and logistics sectors. An Optimizely supply-chain incident also exposed visitors at 178 organizations to cryptocurrency clippers, card skimmers, and iOS exploit kits.

Affected Systems and Products

  • Apple iOS, iPadOS, macOS, tvOS, watchOS, visionOS: Affected by CVE-2026-65339 microphone permission bypass through the audiomxd audio service. Fixed in iOS 26.6.1/iPadOS 26.6.1, iOS 18.7.11/iPadOS 18.7.11, macOS Tahoe 26.6.2, macOS Sequoia 15.8, tvOS 27, watchOS 27, and visionOS 27.
  • ConnectWise ScreenConnect: Client versions prior to 26.6.5 affected by CVE-2026-84869 allowing unauthorized file transfer and execution through active remote sessions.
  • N-able N-central: On-premise and hosted deployments affected by 17 vulnerabilities patched in N-central 2026.4 Hotfix 3, spanning authentication, access control, file handling, server components, legacy APIs, and user management.
  • Optimizely Web Experimentation: Customer projects across 178 organizations injected with malicious JavaScript, including sites belonging to CNN, BBC, Zoom, Salesforce, GitLab, IKEA, HSBC, Equifax, and others.
  • Telegram for Android: Version 13.2.2 (7303) and potentially earlier versions contain widget sandbox bypass issues in QuickJS with seccomp filter in audit mode.

Attack Vectors and Techniques

  • TCC audit token impersonation: An app sends an audit token naming the audiomxd service itself to the audio service, which then treats the app as its own internal process and allows microphone recording without asking TCC, bypassing the orange indicator.
  • Worm-like ScreenConnect propagation: SCKit malware exploits CVE-2026-84869 to execute malicious code on a technician's workstation when they connect to an infected customer device, spreading from customer devices to MSP technicians' computers.
  • N-central authentication bypass: Multiple server components and legacy APIs missing authentication checks allow unauthorized task submission, asset data disclosure, syslog injection, and other server-side actions.
  • Optimizely supply chain injection: Attackers wrote a loader into the Project JavaScript of customer projects; snippets served from cdn.optimizely.com with the vendor's certificate executed the loader on every page load, delivering crypto clippers, card skimmers, and iOS exploit kits.
  • Telegram widget sandbox bypass: Widget JavaScript runs in a single process on Android; a use-after-free or out-of-bounds write in QuickJS lets scripts read and write process memory, bypassing seccomp filter rules that leave ioctl unfiltered.
  • Cloud-based C2 channels: GitDoor uses public and private GitHub repositories for command payloads and result exfiltration; GraphDoor authenticates via Microsoft Graph API and stages data on SharePoint drives, with traffic proxied through Ably messaging.
  • Developer social engineering: Trigram uses fake recruitment portals, conference invitations, and package tracking lures to trick developers into running commands that deploy Overlord RAT and infostealers via JavaScript payloads fetched from GitLab dead drops.

Threat Actor Activities

  • Operation ShadowCloud (Kaspersky): Active cyber intrusion campaign identified in early 2026 targeting government sectors in Asia and Africa. The threat actor abuses the legitimate MeshCentral Agent utility to deploy GraphDoor and GitDoor backdoors, hiding C2 traffic behind Microsoft SharePoint, GitHub, and Ably. The actor's identity is unknown, but Kaspersky notes overlap with China-nexus activity tracked as Bronze Sandcastle by Sophos, with tactical similarities to FamousSparrow and CopperTurtle (BlackTech).
  • Trigram campaign (Stormshield): Large-scale industrialized campaign impersonating about 50 AI and blockchain brands to trick developers into executing infostealers. Assessed with high confidence as a continuation of the UNK_DeadDrop cluster linked to North Korea, particularly Kimsuky. Uses recruitment, conference, and package tracking scenarios with trojanized code repositories and fake VS Code/Cursor extensions.
  • SCKit actors (Huntress, ConnectWise): Unknown threat actors exploiting ScreenConnect and RMM+ authentication flaws to deploy the SCKit multi-component toolkit. Activity impacted 205 hosts across 41 organizations as of November 13, 2026. Associated with bulletproof hosting provider 1337 Services GmbH (IP 185.241.211[.]197). One incident established persistence via a rogue "Windows Update Agent" service running under LocalSystem.
  • 4EverAble2Shell actors: Attackers leveraging N-central flaws to deploy cryptocurrency miners on vulnerable servers. Independent researcher Sean Bales disclosed the flaws and published details for 24 CVEs, noting they are patched on the latest version.
