Exploitation ReportNovember 27, 2026

Executive Summary

Multiple critical infrastructure and enterprise vulnerabilities are currently under assessment, with exploitation statuses ranging from unknown to potential across GeoServer, Drupal, Mitel, Juniper, Danfoss, Xen Orchestra, Palo Alto Networks, and PHP2Shell components. Several flaws carry high or critical CVSS scores and affect internet-facing systems, including GeoServer instances, Drupal core installations, and MiCollab conferencing servers. Patch availability varies, with some vulnerabilities already remediated in vendor releases while others await fixes or rely on mitigations such as network restriction.

Threat actor activity includes confirmed exploitation attempts against GeoServer honeypots, intrusion campaigns against MiCollab instances attributed to unknown actors potentially leveraging AI-assisted techniques, and compromises of Danfoss refrigeration controllers linked to Iranian IRGC-affiliated units. AI-agent-driven attacks are also emerging against critical infrastructure in Switzerland and Italy, with attackers using autonomous frameworks to chain vulnerabilities and misconfigurations at speed. Defenders should prioritize patching where fixes exist and apply network segmentation and monitoring where patching is not immediately possible.

Affected Systems and Products

  • GeoServer: Versions affected by CVE-2026-120705, CVE-2026-120704, CVE-2026-129244, and CVE-2026-129245; affected versions information is blocked in supplied references.
  • Drupal Core: Drupal 8.9, 9, 10, and 11 affected by CVE-2026-132165 and CVE-2026-9082; specific version constraints are blocked in supplied references.
  • Mitel MiCollab: Versions 10.3 and earlier affected by CVE-2026-133311 and related MiCollab flaws.
  • Juniper Session Smart Conductor and Session Smart Router: Affected by CVE-2026-103406; fixed releases encouraged by Juniper SIRT.
  • Vates Xen Orchestra: Affected by CVE-2026-133469 (VSA-2026-062); exploited in the wild.
  • Danfoss AK-SM 8xxA Series: Affected by CVE-2025-41450 and related flaws; used in supermarket and food retail environments across Europe.
  • Palo Alto Networks PAN-OS: Affected by CVE-2026-46300 when management interfaces are exposed to the internet.
  • PHP installations: Affected by CVE-2026-109618 and CVE-2026-109619 (PHP2Shell) across multiple infrastructure vendors.

Attack Vectors and Techniques

  • Unauthenticated Web Feature Service Request: Exploiting CVE-2026-120705 via a single unauthenticated WFS request to read arbitrary files or fetch adversary-selected URLs.
  • Stored Query Manipulation: Creating and invoking stored queries to validate vulnerability and disclose data directory paths, as observed with CVE-2026-129244.
  • Resource Exhaustion Race Condition: Abusing EMFILE, database connection, and TCP source-port limits to bypass Drupal installer checks (CVE-2026-132165).
  • Hard-Coded Signing Key Forgery: Using the predictable "geoserver" signing key to forge administrator authentication cookies (CVE-2026-129245).
  • Command Injection via Salt Minion ID: Sending specially crafted salt minion IDs to execute arbitrary commands as root (CVE-2026-103406).
  • Administrator Session Forgery and JDBC Deserialization: Chaining CVE-2026-120704 with forged administrator sessions to execute code via uploaded native libraries.
  • Authentication Token with Empty JSON Object: Bypassing authentication in Xen Orchestra via a specially crafted token (CVE-2026-133469).
  • PHP Web Worker Code Execution: Running code remotely with PHP web worker privileges via PHP2Shell vulnerabilities (CVE-2026-109618, CVE-2026-109619).
  • Local Privilege Escalation via XFRM Subsystem: Escalating from low-privilege local access to root via the Linux kernel XFRM ESP-in-TCP subsystem (CVE-2026-46300).

Threat Actor Activities

  • Unknown Threat Actor (MiCollab Campaign): Suspected AI-assisted data theft campaign targeting MiCollab instances; deployed web shells, harvested credentials, and stole sensitive business data from line-of-business database servers. A second organization's MiCollab server held a persistent HTTPS channel to threat actor infrastructure since November 9, 2026.
  • Shahid Kaveh / Cyber Aveng3rs / Cyber Isnaad Front (IRGC-linked Iranian unit): Attributed to October 2026 attacks on French supermarket sites that compromised Danfoss AK-SM/AK-SC and Copeland/Dixell XWEB refrigeration controllers and remotely altered defrost settings; subsequent attacks on November 2 affected at least 115 supermarket stores across Belgium, the Netherlands, Sweden, Luxembourg, Ireland, Romania, and Estonia.
  • AI-Agent Threat Actors (Switzerland and Italy): Autonomous AI agents using frameworks such as ARTEX, CyberStrikeAI, PentAGI, and DeepSeek Harness compromised critical infrastructure operators in Switzerland and conducted mass compromise campaigns in Italy; agents chain vulnerabilities, misconfigurations, and compromised credentials, and can write malicious code in real time to evade defenses.
  • North Korean State-Sponsored Actors: Use open-source software registries and GitHub repositories as primary initial access vectors targeting corporate environments, including supply chain poisoning and fraudulent recruitment campaigns.
  • Multiple IP Address Attackers (GeoServer Honeypots): Validated vulnerable GeoServer systems by creating stored queries, checking whether they were created, and deleting them immediately afterward.
