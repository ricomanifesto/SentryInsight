Exploitation ReportNovember 23, 2026

Executive Summary

The only exploitation confirmed as active in the supplied reporting is CVE-2026-20320, a high-severity Cisco BroadWorks vulnerability that CISA added to its Known Exploited Vulnerabilities catalog and ordered federal agencies to patch by November 24 under Binding Operational Directive 26-04. Threat intelligence firm Malbear Labs attributed autonomous AI attacks using this flaw to a Chinese-speaking actor targeting a European telecommunications provider and 13 organizations that used its data centers and cloud infrastructure.

Several other critical flaws are assessed as unconfirmed, potential, or not observed under the supplied evidence rather than as confirmed active exploitation. ConnectWise ScreenConnect CVE-2026-84869 (CVSS 9.9) is now patched; the reporting describes intrusion activity against MSP technician workstations between October 20 and November 16, 2026, but the consolidated exploitation status is unknown. The Idunno.AntiCsrf deserialization flaw CVE-2026-131914 (CVSS 9.3) has no official patch, and the supplied assessment rates exploitation as potential; affected organizations are advised to discontinue the defunct library. N-able Mail Assure SSRF CVE-2026-134624 is fixed (build 20261121.1943) and exploitation is not observed.

Researcher demonstrations and recently patched flaws round out the reporting: Meta Muse was shown in a lab to be compromisable via a malicious webpage chained to a Linux kernel flaw, with all weaknesses fixed before publication; Ghostscript CVE-2026-125396 (sandbox-escape RCE) was patched on September 8 with no attack reports; GPGME CVE-2026-129975 and binary-parser CVE-2026-134814 have no reported exploitation in the supplied evidence. AI offensive frameworks such as ARTEX and Cairn are described as accelerating intrusion and patch-to-exploit chains, with background references to Langflow CVE-2025-3248 and RAGFlow CVE-2026-28797 as targeted application builders.

CriticalExploitable, no attacks seenMitigateCVE-2026-131914#

Reporting
  • The Hacker News — Hackers Exploit Critical ASP.NET Anti-CSRF Library Flaw Allowing Unauthenticated RCE · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: github.com

Earlier reporting
  • CVE-2026-131914. First report of this CVE in the retained archive.
  • Description: An insecure deserialization vulnerability in the Idunno.AntiCsrf ASP.NET IHttpModule lets a remote attacker achieve arbitrary code execution through a single unauthenticated HTTP POST carrying a Base64 .NET ObjectStateFormatter gadget chain.
  • Impact: Complete compromise of the web application server via the IIS worker process.
  • Status: No official patch exists; the open-source project is defunct and has not been updated since December 2008. Google Mandiant reported active exploitation in the wild; per the supplied assessment, exploitation status is potential.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: In the absence of an official patch, organizations still using the library are advised to discontinue its use and replace it with an actively supported anti-CSRF alternative such as System.Web.Helpers.AntiForgery, ASP.NET WebForms Page.ViewStateUserKey combined with MAC-verified/encrypted ViewState on postback forms, or ASP.NET Core Anti-Request Forgery (IAntiforgery). Audit all ASP.NET Web.config files and bin/ directories for references to Idunno.AntiCsrf or AntiCsrfModule, and review IIS logs for anomalous POST requests to .aspx endpoints returning HTTP 302 or HTTP 500 with elevated cs-bytes. Environments with evidence of exploitation should rotate all secrets stored in Web.config and applicationHost.config (including keys, encryption keys, and database credentials) and inspect webroots for unauthorized files.

  • CVE-2026-125396. First report of this CVE in the retained archive.
  • Description: A patched use-after-free in Ghostscript's font loader lets a crafted document disable the -dSAFER sandbox and run commands on the server processing it.
  • Impact: Server command execution as the low-privilege rendering account via upload, preview, or print features in roughly ten common applications.

Bundled and statically linked copies are affected too and need their own rebuilt releases. The advisory offers no interim workaround for software that cannot update yet.

  • The Hacker News — A Single Malicious Webpage Let Researchers Hijack Meta Muse and Access Private Chats · Digest context

Vendor guidance: nebusec.ai, thehackernews.com

  • Description: A malicious webpage opened by Meta Muse could extract a user's private conversations and stored memories without an approval prompt, and researchers chained a built-in browser flaw to a Linux kernel flaw to take full control of the user's isolated cloud machine.
  • Impact: Access to and alteration of conversation history and memories, plus reach into the credential store, saved files, and the Sentinel monitoring layer within a single user's cloud VM; no breakout to other users' machines.
  • Status: Laboratory demonstration, not an attack on real users; Muse's team fixed every weakness described before publication, though Meta has not publicly confirmed the fixes. Per the supplied assessment, exploitation status is unknown.
  • Affected Versions: Not stated in supplied sources.
  • Exceptions: The compromise went no further than that one machine; the researchers did not break out to the shared server beneath it or into other users' machines.
  • Recommended Actions: NebuSec reports that Muse's team fixed every weakness it describes and that the exploits were all fixed before publication.

Affected Systems and Products

  • ConnectWise ScreenConnect: Self-hosted ScreenConnect servers and technician host clients; at least 118 self-hosted servers across 109 Huntress-protected organizations observed with unauthorized guest sessions.
  • Cisco Expressway-C and Expressway-E: Clustered enterprise collaboration gateways deployed as virtual machines or physical appliances.
  • Cisco BroadWorks: Systems used by a European telecommunications provider and 13 customer organizations using its data centers and cloud infrastructure.
  • Idunno.AntiCsrf: ASP.NET WebForms applications using the defunct Idunno.AntiCsrf.dll library versions 0.9.1.0 and 0.9.1 Beta.
  • N-able Mail Assure and SpamExperts Hosted Cloud: Email filtering platform builds earlier than 20261121.1943; Hosted Cloud versus customer-run Local Cloud deployments.
  • Ghostscript: Linux server rendering pipelines (often invoked indirectly by ImageMagick, Pillow, libvips, or Qt plugins) and applications such as WordPress, Roundcube, and Debian print queues.
  • GPGME: Software using GPGME before version 2.3.0 as a shared library, Windows DLL, or static link, including mail clients, XMPP clients, Samba, Gpg4win, GnuPG Desktop, and GnuPG VS-Desktop.
  • binary-parser: Node.js applications using binary-parser versions prior to 2.3.1 with attacker-controlled parser definitions.
  • Meta Muse: Meta's personal AI agent running in individual user cloud computers with connected accounts and stored credentials.

Attack Vectors and Techniques

  • Guest-to-technician file transfer and execution: A malicious ScreenConnect guest pushes a batch file and MSI installer to a technician's host through the client file-transfer channel with no prompt, then launches a rogue ScreenConnect client to an attacker-controlled relay.
  • Hard-coded credentials and weak certificate validation: Unauthenticated attackers invoke remote procedure calls over a database service on clustered Cisco Expressway devices to run arbitrary OS commands as root.
  • Autonomous AI intrusion frameworks: Frameworks such as ARTEX, Cairn, and exploit_agent perform automated reconnaissance, patch differential analysis to derive exploits, multi-agent parallel intrusion, credential theft, and lateral movement with little human involvement.
  • Insecure deserialization: A single unauthenticated HTTP POST containing a Base64 .NET ObjectStateFormatter gadget chain is deserialized without MAC verification to achieve remote code execution on IIS.
  • SSRF via LDAP synchronization: An authenticated high-privilege API user directs an internal connection check to arbitrary hosts and ports to enumerate and reach internal services.
  • Malicious webpage to container escape: A page opened by an AI agent reads stored conversations and memories, then chains a built-in browser flaw to a Linux kernel vulnerability to escape the agent runtime container and obtain root on the underlying user VM.
  • Ghostscript sandbox escape via crafted uploads: Crafted PDF/PostScript/image content is routed to Ghostscript through common image/document libraries and WordPress upload, preview, or print paths to escape -dSAFER and execute commands.
  • Double-free via long OpenPGP user IDs: Malformed key material causes freed memory to be released again in GPGME status-line parsing routines, enabling data theft or potential code execution.
  • JavaScript injection via parser definitions: Unvalidated string options are inserted directly into generated JavaScript during binary-parser compilation, executing attacker-controlled code in the Node.js process.

Threat Actor Activities

  • Armory Castle (formerly UNC5221), suspected China-nexus: Attributed to zero-day exploitation of VMware vCenter CVE-2026-123890 (authentication bypass) in early September 2026, following earlier BeyondTrust zero-day access, and deployed backdoors on Linux machines.
  • Chinese-speaking threat actor: Abused Cisco BroadWorks CVE-2026-20320 in autonomous AI attacks against a European telecom provider and 13 organizations; F6 also observed AI-assisted exploitation of Cisco Expressway for root access and lateral movement on Internet-exposed devices.
  • CL-STA-1238, Chinese-speaking: Used Cairn paired with GLM and DeepSeek to autonomously conduct 25 operations against at least 19 organizations, including semiconductor manufacturing, U.S. defense policy, and civil society targets, and discovered the MONAI Label zero-day GHSA-qc22-rmgc-vg94 to gain server control in 11 minutes.
  • Crafty Falcon: Conducted AI-driven attacks on Indian financial firms using ARTEX, PentAGI, CAIRN, and CyberStrikeAI; CERT-In linked AI-assisted attacks to unauthorized transactions at banks, NBFCs, and fintechs.
  • Webworm, China-aligned: Deployed a modified SoftEther VPN Bridge build (netcapa.exe / NtMonitor VPN, version 4.44 build 9807) with altered HTTP endpoints and watermarks to evade detection and establish covert remote access.
  • Cold Relic, Russian cyberespionage: Converted cloud administrator compromise into social-engineering attacks by impersonating employees across trusted partner organizations.
  • Noiem (alias, unconfirmed): Claimed the KEPCO breach of 1.5 million individuals on a hacker forum; attribution remains unconfirmed.
  • Lazarus Group / North Korea: Associated with Kruw.io coinjoins obscuring stolen funds from the Binance, Bitget, and Bybit hacks.
  • Unknown operators: Unauthorized ScreenConnect guest sessions from cryptocurrency-themed hostnames and a single IONOS IP; LaLiga fan-data breach with no ransomware group claiming responsibility; KEPCO initial access method not disclosed.
