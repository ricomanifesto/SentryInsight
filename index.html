Exploitation ReportNovember 20, 2026

Executive Summary

Multiple critical vulnerabilities across virtualization, web server, and application ecosystems are assessed in this reporting period. The VMware vCenter Server authentication bypass tracked as CVE-2026-123890 is linked to Chinese-linked threat actor Armory Castle, which exploited the flaw in zero-day attacks beginning in early September 2026 to gain administrative access to vCenter environments. Separately, two NGINX HTTP/2 vulnerabilities tracked as CVE-2026-123007 and CVE-2026-123633 could allow unauthenticated remote code execution, with exploitation status assessed as unknown based on the supplied evidence.

CVE-2026-90436 affecting Apache Axis is assessed as actively exploited, with Rapid7 detecting exploitation against Atlassian Confluence Data Center in a customer environment; the flaw is associated with cryptocurrency miner deployment alongside 4EverAble2Shell vulnerabilities. Additional critical flaws in PHP, Oracle, MySQL, PostgreSQL, ASUS management products, and Synology DSM require patching where updates are available, though exploitation status for these items remains unknown in the supplied sources.

Defenders should prioritize patching for all vulnerabilities with available fixes, apply mitigations where patches are unavailable, and review exposure to actively exploited flaws such as CVE-2026-90436. The report preserves negative and conflicting evidence for each finding, and no CVE is described as actively exploited unless the supplied evidence and status contract support that conclusion.

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: thehackernews.com, depthfirst.com, github.com, php.net

Earlier reporting
  • CVE-2026-126714. First report of this CVE in the retained archive.
  • Description: A Time-of-check Time-of-use vulnerability that could result in the execution of arbitrary code with the privileges of the PHP worker, also known as phpAfterShell.
  • Impact: Attackers can manipulate partially overwritten session files to achieve remote code execution by chaining with a deserialization gadget chain or second memory-corruption bug.
  • Status: Exploitation status is unknown per the supplied assessment; neither maintainers nor Depthfirst report any attacks using phpAfterShell. Patches are available in PHP 8.2.36, 8.3.37, 8.4.28, 8.5.13, and 8.6.0.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Sessions kept in Redis, a database, or another store are outside this defect; PHP 8.1 and older official end-of-life mitigation branches for 7.4, 8.0, and 8.1 are not affected, but older unpatched builds of those versions are.
  • Recommended Actions: Install the fixed release for your branch. If you cannot update yet and your app does not use upload progress, set session.upload_progress.enabled = 0 in php.ini or the server's PHP settings, then restart the PHP workers. Switching the feature off is not a full fix; moving sessions to a store that replaces records in one step also avoids this defect.

Attack Vectors and Techniques

  • Authentication Bypass: Unauthenticated network attacker bypasses VMware Directory Service authentication to establish an administrator session in vCenter
  • Vector: Network access to vulnerable vCenter Server via DCE/RPC interface
  • Remote Code Execution via Memory Corruption: Flow-control and use-after-free bugs in NGINX HTTP/2 workers allow unauthenticated code execution
  • Vector: HTTP/2 connections to an NGINX listener, potentially with backend proxying
  • Unsafe Reflection: Unauthenticated remote attacker executes arbitrary code through Apache Axis XML-RPC and SOAP APIs
  • Vector: Crafted HTTP requests against Confluence Data Center with Remote API enabled
  • PHP Request Smuggling: Attacker-controlled PHP code executed as the worker through reused backend connections to PHP-FPM
  • Vector: Web servers with persistent FastCGI/PHP-FPM backend connections (nginx fastcgi_keep_conn, Apache mod_proxy_fcgi enablereuse, HAProxy, LSAPI)
  • Session TOCTOU: Interrupted session write creates mixed session state leading to deserialization and code execution
  • Vector: Multipart form upload with upload progress enabled, followed by session_start() call
  • Code Injection: Crafted file-path or stream parameter during data import processing in REDCap public survey context
  • Vector: HTTP requests to unintended controller routes requiring a valid public survey hash
  • Physical Lock Screen Bypass: Physical access to locked Windows computer with Microsoft account recovery options and Narrator screen reader
  • Vector: Local physical access to the lock screen
