Executive Summary

F5/nginx disclosure activity centers on a decade-old NGINX HTTP/2 flaw, CVE-2026-123007 (“nginx2root”), which allows unauthenticated code execution on HTTP/2-enabled servers with worker-process privileges; root compromise would require a separate privilege-escalation path such as the Linux kernel SCTP bug. Fixed versions 1.31.9 and 1.30.7 were released, a public proof of concept exists, and neither the vendor nor researchers reported observed exploitation or CISA KEV listing as of publication; the scoped exploitation status is unknown. Four related same-scored NGINX flaws require narrower configurations, including HTTP/2-to-backend setups, proxied server names with SSI or mirror subrequests, HTTP/3, and NGINX mail proxy use.

Oracle/OpenJDK Java4Shell, CVE-2026-114938, is assessed as not_observed: patches have been released by Oracle and OpenJDK, with Amazon Corretto fixed and Red Hat fixes still pending, but Canada’s Cyber Centre and related reporting had no evidence of wild exploitation at publication. Exploitation requires x86-64 CPUs with AVX-512 VBMI and can reach unauthenticated Base64-processing paths such as HTTP Basic, SAML artifacts, and CSRF tokens; temporary JVM flags are available if immediate patching is not feasible.

Other critical items include six F5 BIG-IP Traffic Management Microkernel stack buffer overflows, including CVE-2026-123637, CVE-2026-121805, CVE-2026-120292, CVE-2026-120285, CVE-2026-116953, and CVE-2026-120722, which can crash TMM and may allow remote code execution in specific iRule or APM configurations; fixes are engineering hotfixes only with no listed workaround, and the scoped exploitation status is unknown. The advisory also references CVE-2026-94127 as a separate previously disclosed BIG-IP APM flaw; this report does not assert confirmed exploitation for that reference. AMD CVE-2026-43613 involves physical TPM lockout reset for Windows Hello/BitLocker PIN guessing, with firmware fixes planned and PIN-length mitigations recommended. Separate threat activity involves EggStreme, Mustang Panda, Earth Alux, Cold Relic, and Scattered Spider campaigns targeting government, telecom, cryptocurrency, and enterprise environments.

Vendor guidance: nginx.org, my.f5.com, circl.lu

Earlier reporting
  • CVE-2026-123007. First report of this CVE in the retained archive.
  • Description: A decade-old NGINX HTTP/2 flaw lets unauthenticated attackers execute code with NGINX worker-process privileges when HTTP/2 is enabled; gaining root requires a separate privilege-escalation path, such as the Linux kernel SCTP bug.
  • Impact: Attackers can run code on vulnerable servers; in tested environments, worker-process code execution could lead to host compromise through a separate SCTP bug, including inside Docker containers.
  • Status: Exploitation status is unknown. No attacks exploiting CVE-2026-123007 have been reported by the vendor, Wiz, or Rapid7, and CISA KEV did not list it as of publication. A public proof of concept exists, limited in notes to a freshly started Docker container on the same machine. Fixed versions 1.31.9 and 1.30.7 are available.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: None stated in supplied sources.
  • Recommended Actions: Upgrade to NGINX Open Source 1.31.9 or 1.30.7, or fixed NGINX Plus builds, and restart NGINX fully or use its live binary upgrade; a reload alone leaves old workers running. Until patched, turn off HTTP/2 per CIRCL guidance, which blocks CVE-2026-123007 and CVE-2026-123633 but not the other flaws; for hosts not using SCTP, block the sctp kernel module from loading, for example with install sctp /bin/false in /etc/modprobe.d/. Monitor for NGINX workers starting unexpected programs, abnormal worker exits or core dumps, long-lived HTTP/2 connections with heavy incoming traffic and few logged requests, and unusual outbound connections or DNS lookups.

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: cve.org, openjdk.org, oracle.com, cisa.gov, keycloak.org

Earlier reporting
  • CVE-2026-114938. First report of this CVE in the retained archive.
  • Description: An out-of-bounds write in the hardware-accelerated Java Base64 decoder on x86-64 CPUs supporting AVX-512 VBMI can lead to denial of service or remote code execution. Malformed Base64 input can reach the decoder before authentication through paths such as HTTP Basic login headers, SAML artifacts, and CSRF tokens.
  • Impact: JVM crash or unauthenticated remote code execution on affected Java applications under conditions. There is no universal exploit; each target requires its own memory layout and timing, and failed attempts can crash Java.
  • Status: Exploitation status is not_observed. Canada’s Cyber Centre and related reporting had no evidence of wild exploitation at publication. Patches were released by Oracle and OpenJDK; Amazon Corretto fixed builds are available, while Red Hat fixes were not yet released. Severity ratings differ by vendor: Calif rates CVSS 4.0 at 9.2, Red Hat preliminarily at 9.8, and Oracle at CVSS 3.1 8.1.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Standard Java 8 and Java 11 do not contain the vulnerable code; ARM64 chips do not run the vulnerable AVX-512 VBMI decoder.
  • Recommended Actions: Apply available Oracle/OpenJDK fixed builds and restart Java services, rebuilding and redeploying container images so running processes use the new build. If immediate patching is not feasible, start OpenJDK with -XX:-UseBASE64Intrinsics or, on x86-64 systems, -XX:UseAVX=2 as temporary mitigations; note that -XX:DisableIntrinsic=_base64_decodeBlock can prevent Java from starting. Keycloak deployments should check for avx512vbmi and apply temporary mitigations until updated images are available.

MediumExploitation unknownMitigateCVE-2026-43613#

Reporting
  • The Hacker News — New Attack Bypasses TPM Lockout to Crack Windows Hello and BitLocker PINs in Days, Not Years · Digest context

Affected versions unresolved. Review the linked reporting before inferring an affected version range.

Vendor guidance: amd.com, intel.com

Earlier reporting
  • CVE-2026-43613. First report of this CVE in the retained archive.
  • Description: On affected firmware-TPM PCs, the wrong-PIN lockout for Windows Hello and BitLocker can be reset by restoring an old flash state, or on Winbond RPMC flash by extracting a counter-signing key through voltage glitching, enabling short-PIN guessing.
  • Impact: Short Windows Hello and BitLocker PINs can be brute-forced after physical access and mainboard tampering; measured worst-case times fall from days or years to hours or days.
  • Status: Exploitation status is unknown. The researchers describe no attacks outside the lab. AMD confirmed a firmware flaw for some AMD PCs and plans fixes from November 2026 to February 2027 across Ryzen, Ryzen AI, Ryzen Threadripper, Athlon, and EPYC chips, with one unnamed product undated. Intel stated the research did not demonstrate an Intel component vulnerability; Microsoft rated the Hello report moderate and did not issue an immediate fix or CVE.
  • Affected Versions: Unresolved from supplied sources.
  • Exceptions: Three Intel systems detected the same write-back in tests; AMD bulletin does not cover AMD PCs without RPMC flash.
  • Recommended Actions: Raise minimum Windows Hello and BitLocker PIN lengths, use enhanced PINs where supported, keep affected AMD PCs under physical control, and watch for tampering until firmware updates are available. Install AMD firmware fixes when available for the specific PC; Intel customers should ask their PC maker about updates. Winbond has not committed to a fix or date.

Affected Systems and Products

  • NGINX Open Source and NGINX Plus: HTTP/2-enabled NGINX servers, including NGINX Open Source 1.9.5 through 1.31.8 with fixed releases 1.31.9 and 1.30.7; NGINX Plus 37.x before fixed builds and R34 to R36. Official Docker images tagged 1.31.9 and 1.30.7 were available, including Alpine variants; Ubuntu and Debian had not shipped fixed packages as of publication, though package versions may still carry fixes.
  • Oracle/OpenJDK and downstream Java runtimes: Java 17.0.6 and later, Java 21, 25, and 27, Java SE 8 Performance Pack build 8u511b33-perf, and affected GraalVM builds, but only on x86-64 CPUs with AVX-512 VBMI. Exposed applications include Keycloak, Atlassian Jira, Atlassian Confluence, JFrog Artifactory, Jenkins, and PingFederate unauthenticated, and Apache Kafka Broker, Apache Solr, Elasticsearch, Gerrit, and Spinnaker with authentication.
  • F5 BIG-IP: BIG-IP, BIG-IP Next for Kubernetes, and BIG-IP CNF in specific virtual-server iRule or APM policy configurations. Fixed BIG-IP Next for Kubernetes builds include BNK-2.4.2-EHF1, BNK-2.3.4-EHF1, and BNK-2.2.5-EHF1; BIG-IP CNF EHF builds apply to CVE-2026-121805 and CVE-2026-120285. The management side is not exposed.
  • AMD and Intel Windows devices: Firmware-TPM PCs, particularly AMD Ryzen, Ryzen AI, Ryzen Threadripper, Athlon, and EPYC systems with RPMC flash, and systems using Winbond RPMC flash regardless of processor. Tested devices included an HP OmniBook and a Framework Laptop.

Attack Vectors and Techniques

  • Unauthenticated NGINX HTTP/2 integer underflow: Attacker sends crafted HTTP/2 traffic to a reachable HTTP/2 port; Rapid7’s demonstration needed about 128 GB of HTTP/2 traffic and an AVX-512 glibc memcpy path, and could fail on links below about 300 Mbit/s because of NGINX’s default one-hour connection limit. Worker-process execution can lead to root through a separate Linux kernel SCTP bug.
  • Pre-authentication OpenJDK Base64 decoder overflow: Malformed Base64 input is decoded by the AVX-512 VBMI-accelerated decoder before login in paths such as HTTP Basic, SAML, and CSRF; attackers combine the fixed out-of-bounds write with memory grooming and JavaBleed to reach code execution. No universal exploit exists.
  • F5 BIG-IP TMM stack overflows: Unauthenticated traffic matching configured triggers, including iRule commands such as PEM::subscriber, MR::message route, PSC::ip_address, GENERICMESSAGE::route, or DNS::scrape, or an APM per-request policy with Client Information plus Endpoint Security agents, crashes TMM and may allow RCE.
  • Puppet deserialization reference context: A client holding any CA-signed agent certificate submits a crafted rich-data type through a PUT request to Puppet report-processing code; automatic CA signing can allow an unauthenticated network attacker to obtain a valid certificate.
  • TPM PIN lockout reset: Physical interposer between processor and flash restores old flash state to reset wrong-guess counters; Winbond RPMC key leakage through voltage glitching forges counter values, enabling PIN brute force for Windows Hello and BitLocker.
  • Compromised third-party JavaScript: Malicious JavaScript served through Optimizely to 178 organizations without user interaction or consent; weak or absent Content Security Policy allowed payload delivery and iOS zero-click exploit kits.
  • Malicious PyPI startup hooks: Malicious agent-framework 1.26.1 and 1.26.2 install .pth files that execute on every Python start and steal environment variables, credential files, Azure/GitHub tokens, and instance metadata, exfiltrating to a webhook.site endpoint.
  • DLL sideloading and credential theft: Threat actors use sideloaded DLLs under system library names, staging through unmanaged hosts and VBScript over SMB, Exchange web shells, phishing decoys, SIM swapping, and MFA fatigue.

Threat Actor Activities

  • EggStreme operators, suspected Chinese APT: Rebuilt toolkit targeting Philippine government organizations; new network protocol, passive non-beaconing variant, RC4-to-RC5-to-custom-cipher changes, and campaign-specific certificate authorities. Initial access remains unknown; some components overlap CL-STA-1048 activity from March to September 2025, but attribution is not confirmed. Possible Taiwan targeting assessed at low-to-medium confidence.
  • Mustang Panda: As of late October 2026, targeted Philippine government officials with ASEAN Summit lures, including a decoy Laos–Philippines bilateral meeting agenda, delivering PlugX through DLL sideloading.
  • Earth Alux, aka Ink Dragon, Jewelbug, REF7707, UAT-11587, TGR-STA-0049: Targeting Southeast Asian government entities since at least July 2025; gains initial access through unpatched Microsoft Exchange servers or phishing PDFs and lookalike domains; deploys FINALDRAFT since 2023, PerfectPioneer RAT from July 2025, and KUKURAT from March 2026. Uses lateral movement via unmanaged hosts, VBScript over SMB, PsExec, WMI, and WinRM; collects credentials with Mimikatz, ProcDump, and SharpDPAPI; compromises domain controllers; and uses HTTP/3 and QUIC for C2.
  • Cold Relic, aka Callisto, Gossamer Bear, Star Blizzard, UNC4057: Russia-linked group weaponizing one cloud compromise to intrude a second organization; uses stolen Super Admin and Entra ID credentials, rogue MFA devices, passkeys, and backup codes for persistence, exfiltrates via Google Takeout, and conducts impersonation-based social engineering against government, defense, and NGO targets in Europe and North America.
  • Scattered Spider, aka 0ktapus, Octo Tempest, UNC3944, Muddled Libra: English-speaking cybercrime collective using SMS phishing, MFA bombing, phishing, and SIM swapping; one leader sentenced to six years and over $11.6 million in cryptocurrency theft alleged. Historically linked to Caesars, Riot Games, MailChimp, Twilio, DoorDash, and Reddit, and has partnered with BlackCat/AlphV, Qilin, and RansomHub.
